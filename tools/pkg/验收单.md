## 一、三步验收

```powershell

# 2. 验收（五项：指纹 / 全链+门槛 / 回归测试 / MCP 工具 / 关键数字）
powershell -ExecutionPolicy Bypass -File .\verify.ps1

# 4. 值班台（本地 Web 壳，问一句 / 看八份产物）
powershell -ExecutionPolicy Bypass -File .\start_web.ps1
# 浏览器打开 http://127.0.0.1:8765
```

### 两条安装路径

| 验收机情形 | 走法 |
|---|---|
| 能访问 PyPI | 按上面三步，`install.ps1` 建 venv 装依赖 |
| **不能访问外网** | **跳过 `install.ps1`**：确认系统 Python 已有 numpy / scipy / rasterio / pytest，直接跑 `verify.ps1`——它会自动回退到系统 Python，五项检查照常执行 |

`install.ps1` **需要联网**，本包不内置 wheel。包内代码与数据是离线的，依赖不是。

## 三、验什么

1. **可复算**：`python -m typhoeus.cli run` 重跑后指纹不变，`out/` 全部产物重新生成且数值一致。
2. **口径闭环**：05 与 06 的门槛统计必须相等；不一致即交付包自相矛盾。
3. **拒绝能力**：域外查询抬 `RefusalError`，不返回估计值；弱基线不给排序；缺口径不返数字。
4. **只读边界**：MCP 服务只读 `out/`，不重跑内核、不改参数、不写文件。
