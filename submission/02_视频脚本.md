# 材料 02：演示视频脚本（≤3 分钟）

时长目标 **2 分 40 秒**（留 20 s 余量）。全程屏幕录制，无真人出镜，纯命令 + 产物展示。

**核心叙事**：不演"模型算得多准"，演"**模型会告诉你哪里不能信**"。
这是本案与其它参赛作品的真正差别，也最符合 Sci2U「凡人亦科学」的场域。

## 录制清单（按顺序执行，每步都验证过）

```bash
# 1) 全链（先跑一次，视频里录第二次就快了）
python -m typhoeus.cli run

# 2) 情景落档
python -m typhoeus.cli scenario 338.8

# 3) 决策可行域
python -m typhoeus.cli decide

# 4) 规划决策卡（浏览器打开）
start out/p32_规划决策卡.html
```

**打开的产物（按镜头顺序）**：
1. `out/p32_规划决策卡.html` ← 主角
2. `out/p6_情景矩阵.json`
3. `out/p34_逐场四色面积.json`（可选，展示 8/18 场有红格）

---

## 三条录制纪律

1. **不要念 caveat**。边界已经在画面里（决策卡的可信度列），说出来反而拖时间。
2. **1:50 那个镜头是全片唯一必须让观众记住的**——"28 个点里只有 4 个能承载建议"。
   这句话如果只留一句，就留这句。
3. **终端字号调大**（≥18 pt）。评审在小窗看，字号小了等于没演。
