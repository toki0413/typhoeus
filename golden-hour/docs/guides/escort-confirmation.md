# 逐名确认与短途护送 · 操作说明

> 适用版本：2026-11-23 多区域构建（默认 5 区域 10 人）。
> 适用入口：`building.html` 默认多区域模式；`?zones=single` 为旧单区域模式，不使用本机制。

---

## 1. 机制一句话

救到居民不等于救出：先把人带离原位，再走回本区域门口按“确认送达”，才计入获救。
全部区域确认完后，还要返回入口撤离，才结算整局。

---

## 2. 一局流程

```
进入区域 → 找到居民 → 牵/背带离 → 走回区域门口 → 确认送达
        → 本区 2 人都有结果 → 自动切下一区
        → 5 区全部完成 → 阶段变为“返回入口” → 走回入口 → 结算
```

- 每个区域固定 2 名居民：1 名可见、1 名躲藏。
- 区域完成条件：2 人都已确认获救，或已经失去。
- 5 个区域全部完成后，不会立刻结算；必须返回入口。

---

## 3. 操作

### 3.1 移动

| 平台 | 操作 |
| --- | --- |
| 桌面 | `W/A/S/D` 或方向键 |
| 触屏 | 屏幕底部方向键（D-pad） |

- 只能在当前区域或撤离目标房间内移动。
- 靠近躲藏居民 2m 内，居民才会出现在居民列表和剖视图中。
- 进入火源格会快速累积烟热暴露，注意绕开。

### 3.2 带离居民

在居民面板选择：

| 按钮 | 适用 | 耗时 | 说明 |
| --- | --- | --- | --- |
| 牵 | 清醒居民 | 4 秒 | 不增加负重；昏迷或健康归零时不可用 |
| 背 | 任何人 | 5 秒 | 昏迷只能背；带离期间目标受到保护 |

- 带离需要靠近居民（约 2m 内）。
- 带离成功后，居民状态变为“待确认”，并解除躲藏。
- 此时**还没有计入获救**。

### 3.3 确认送达

1. 走回本区域门口。门口就是进入房间的一侧，坐标为房间内的门侧入口。
2. 距离门口 1.5m 内，居民行出现“确认送达”按钮。
3. 点击“确认送达”。
4. 成功后才计入 `救出 x/10`。

> 提示：待确认的居民仍会继续受到烟热伤害。不要把人带离后长时间不确认。

### 3.4 撤离

- 5 个区域全部完成后，HUD“阶段”变为“返回入口”。
- 路线目标自动切回入口。
- 回到入口即结算：标题显示“救出 x/10 · 已撤离”。
- 撤离途中玩家倒地，按失败结算。

## 4. 界面对照

| 位置 | 含义 |
| --- | --- |
| HUD“阶段” | 搜救 / 返回入口 / 撤离完成 |
| HUD“目标” | 当前区域；撤离阶段为入口 |
| HUD“居民” | `救出 x/10 · 区域 y/5` |
| 区域条 | 5 个区域的状态：待救 / 进行 / 完成；全部完成后追加“返回入口撤离” |
| 居民状态 | 平静 / 恐慌 / 躲藏 / 昏迷 / 待确认 / 已失去 |
| 居民按钮 | 牵 / 背 / 确认送达 |

## 5. 常见提示与处理

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 离居民太远 | 距离超过救援半径 | 先移动靠近 |
| 没找到 | 躲藏居民在 2m 外 | 在房间内搜索角落 |
| 昏迷只能背 | 居民健康归零 | 改用“背” |
| 已经失去 | 居民死亡 | 无法再救，等待本区结束 |
| 尚未带离 | 直接点了确认 | 先牵/背带离 |
| 离门口太远 | 确认时超过 1.5m | 走到门侧入口再确认 |
| 已确认 / 已带离 | 重复操作 | 该居民已处理，换下一名 |
| 你被烟和热压倒了 | 暴露累积到上限 | 注意低姿、空呼与撤离时机 |

---

## 6. 节奏与取舍

- 每名居民需要“一次带离 + 一次走回确认”，比旧版直接救出更耗时。
- 10 名居民意味着至少 10 次短途往返；越晚确认，居民越可能倒在烟里。
- 空呼气瓶约 120 秒，移动消耗更快；满编流程会在末段耗尽空呼。
- 工具、破拆与排烟会改变烟路，直接影响待确认居民能否撑到门口。
- 评分会同时考虑获救人数、用时、峰值暴露、错误灭火剂与区域完成数。
