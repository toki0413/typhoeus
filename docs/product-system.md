# 提比翁（Typhoeus）产品功能体系

时间 2026-10-17。本文把分散的 31+ 件产物收拢为一张功能体系图，
供提交材料、路演与后续开发共用。每件功能都标：产物件号、可判定口径、当前三态。

**定位一句话**：不做平台、不做设计院——做嵌在既有监测之上的**可复算
决策层**：把一场雨翻译成"该修哪里、修多少、这条结论可不可信"。

---

## 〇、体系骨架：一核 · 三层 · 五步

```
                 ┌─ 三条腿（学科支柱）
                 │   ① 气象科学 ② 城市建设与土木工程 ③ 打破信息不对称
                 │
 输入            │     三层任务链（赛道结构）          五步方法链（操作序列）
 ─────           ▼                                   ▼
 台风路径 ──→ ① 复合风险识别 ──→ μ_t 测度/四档分级
 IBTrACS      ② 影响评估     ──→ Q(t)/归因/恢复次序/生命线
 ERA5/CHIRPS  ③ 应急信息转译 ──→ 涝点卡/决策卡/可信度标签 ──→ ①分级②病因③手段④门槛⑤可信度
 通报台账
                 │
                 ▼
            物理内核（共享底座，37 s 全链）
            质量守恒水动力 + Green-Ampt 入渗 + 排水项 + 情景矩阵
```

两层不一对一拼装：腿一的误差必须经腿三的控制项才允许出口。

## 七、明确不做清单（与功能体系同等重要）

1. 逐点水深承诺（17 点命中 0%，根因管网台账+DSM 分辨率）
2. 点位排序建议（秩技能未确立，p25 证伪）
3. "几点到水"的演进时序（起水同步，提前量带宽 1.3 h）
4. 资源类作业单（需台账+决定权）
5. 风灾读数、设施施工图、造价表、颜值评判
6. 重现期外推（GPD 样本量不足，经验频率只报样本内）
