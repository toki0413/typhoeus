# 要不要引入碳定价

时间 2026-10-17。本文回答一个概念性问题：**我们的产品该不该引入碳定价。**
结论先行：**不该作为主线引入，但可以成为碳定价链条的末端一个模块；
另外有一条相邻且更值钱的路被这个名字挡住了——风险定价。**

---

## 一、先分清两件事：碳定价是减排工具，我们是适应工具

| | 碳定价 | 本产品 |
|---|---|---|
| 作用对象 | **排放** | **降雨与排水** |
| 目标 | 减少未来的扰动 | 承受已发生的扰动 |
| 经济角色 | 内部化外部成本 | 内部分配适应投资 |
| 时间尺度 | 十年—百年 | 小时—年 |

**它们在逻辑上不重叠。** 要把碳定价接进来，必须**先建一条因果链**：

```
排放 → 全球增温 → 台风强度/频次 → 本地降雨 → 积水 → 功能损失
 ①        ②            ③             ④        ⑤      ⑥
```

**我们手上只有第 ④–⑥ 环**（降雨 → 积水 → 损失，`Q ∝ 雨量^2.109`）。
第 ①②③ 环不在我们手上，**而且 CC 标度已被本项目标为 BLOCKED**
（`07_multievent_calibration.json` 的 `CC标度` 段：18 场全在同一气候态内，标不出来）。

> **所以"引入碳定价"等于承诺一条我们建不起来的链。**
> 这一条必须先说清，否则后面所有讨论都是空转。

---

## 二、三个可能的接入点，逐一判定

### 接入点 ①：作为「归因乘子」的提供方 —— ✅ 可行，且干净

极端事件归因（event attribution）的标准做法给出一个
**可归因比例 FAR**（人为因素造成的风险占比）。若某项研究给出
"人为增暖使本场降雨增强 X%"，那么我们能立刻给出**损失增幅**：

```
损失倍数 = (1 + X)^2.109
```

实测乘子表：

| 降雨增强 | 损失增加 | 倍数 |
|---|---|---|
| +2% | **+4.3%** | 1.043 |
| +5% | **+10.8%** | 1.108 |
| +10% | **+22.3%** | 1.223 |
| +15% | **+34.3%** | 1.343 |
| +20% | **+46.9%** | 1.469 |
| +30% | **+73.9%** | 1.739 |
| +50% | **+135.2%** | 2.352 |

反解：**损失翻倍需要降雨增加 38.9%**（2^(1/2.109) = 1.389）。

**这一条的价值**：
- 它是**唯一**我们能对归因科学做出的贡献——把"降雨增强多少"翻译成"损失增加多少"
- 它不越界：我们不宣称 X 是多少，只提供函数
- 它可直接作为 SCC / FAR 研究的**下游模块**

### 接入点 ②：用碳汇抵消海绵城市投资 —— ❌ 算了，约 1%，不值得

蓝绿基础设施（湿地、下沉绿地）既减涝又固碳，理论上可用碳价补贴。
按 p29 实测的域内公共空间面积算量级：

| 项 | 值 |
|---|---|
| 公共空间面积（p29 实测） | **422.4 ha** |
| 城市绿地固碳速率（文献量级） | 约 3 tCO₂/ha/yr |
| 年固碳量 | 约 **1 267 tCO₂/yr** |
| 中国碳市场价 ¥70–100/t | **¥8.9 万 – 12.7 万 / 年** |
| 若用 SCC（约 ¥370/t） | 约 ¥47 万 / 年 |
| **对照：下沉 0.3 m 改造投资** | **百万 – 千万级（一次性）** |

> **抵消率约 1%（市场价）到 5%（社会成本价）。**
> **碳价救不了海绵城市的经济性。** 这条路口算一下就关掉。

### 接入点 ③：自己算碳的社会成本（SCC）—— ❌ 不可行

SCC 需要"排放 → 损害"的完整链条，起点是 ①②③ 环。
我们缺 FAR，也缺排放情景。**做不了，也不该假装做得了。**

---

## 三、这个名字挡住了另一条更值钱的路：风险定价（不是碳定价）

用户提"碳定价"时，真正想解决的可能是**"把气候风险变成钱"**。
如果是这个诉求，碳定价是错的工具，**风险定价才对**：

| | 碳定价 | **风险定价** |
|---|---|---|
| 定价对象 | 一吨 CO₂ | **一处资产的年期望损失** |
| 需要什么 | 排放-损害全链 | **损失超越曲线** |
| 我们有没有 | ❌ | **✅ 有素材** |

**为什么我们有**：
- `Q ∝ 雨量^2.109`（14 场标定，R² 0.883）→ 给定雨量分布就能算损失分布
- 四情景轴（总量/集中度/排水/土壤）→ 可做条件化
- **宁波是巨灾保险首批试点城市（2014 年起）** → 有真实需求方

**这一步需要补的只有一件**：把 18 场的 Q 值整理成**损失超越曲线**
（exceedance probability vs loss），这不需要新数据。

---

## 四、我的判断

| 选项 | 判定 | 理由 |
|---|---|---|
| **把碳定价写进主线定位** | ❌ **不做** | 因果链前三环不在手上；CC 标度已 BLOCKED |
| 提供「归因乘子」作为下游模块 | ✅ **可做** | 干净、不越界、是我们唯一能贡献的一环 |
| 用碳汇补贴海绵城市 | ❌ **不做** | 实测抵消率约 1%，不值 |
| **改做风险定价（损失超越曲线）** | ✅ **最值得** | 素材已有、需求真实（巨灾保险试点城市） |

### 一句话

> **碳定价问的是"排放一吨该付多少"，我们答的是"挨这一场雨会损失多少"。**
> 两者之间隔着四环因果，我们只占最后一环。
>
> **不该为了一个热词，去承诺一条建不起来的链。**
> 但可以把我们那一环做成干净的乘子，交给真正在做归因的人。

---

## 五、边界

1. `Q ∝ 雨量^2.109` 来自 14 场历史气旋标定，**外推到 +30% 以上属标度外推**，
   未经实测验证。
2. 绿地固碳速率 3 tCO₂/ha/yr 是**文献量级**，未用本地实测；
   碳价取 ¥70–100/t（中国碳市场区间）与 ¥370/t（SCC 量级）两档。
3. 中国碳市场价与国际 SCC 差 3–5 倍，两者不可混用，文中已分别标注。
4. **本项目不做归因科学**：X 是多少由归因研究给出，我们只提供 `(1+X)^2.109`。
5. 损失超越曲线尚未产出；本文只说"素材已有"，不等于已做完。
6. 巨灾保险试点是**公开事实**，但**我们与该体系无任何合作**。
