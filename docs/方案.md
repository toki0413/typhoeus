# 方案：台风暴雨城市内涝风险推演与涝点决策支持

时间 2026-10-17。这是收敛稿。**每条主张后面都跟着它自己的证据编号与边界。**
产物 36 件（`out/p0`–`p35` + `01`–`08`），提交 50+ 次。

---

## 一、定位（一句话）

> **给定一场台风暴雨的面雨量与时间分布，回答"哪些涝点必须动、该用什么手段、要做到什么程度"，
> 并明确标出哪些结论能信、哪些不能。**

**不做的**：实时调度指挥、施工图设计、法定预警发布、跨灾种综合评估。

**赛道名称**沿用赛事官方口径：**「浙江台风内涝」**（《参赛数据源汇总》topic 5152 第 5 项）。

---

## 二、产品形态：五步决策链

```
给定雨量 → ① 分级 → ② 找病因 → ③ 定手段 → ④ 算门槛 → ⑤ 标可信度
```

| 步 | 输出 | 依据 |
|---|---|---|
| ① 分级 | 响应等级、值守频次、人员装备、布点数 | 四色阈值（GB 51222 口径） |
| ② 病因分型 | 排水兜底 / 排水可挖 / 雨致 / 无汇流 | p17 三系数自对照 |
| ③ 定手段 | 保运行 / 加管径 / 调蓄 / 补几何 | 分型映射 |
| ④ 门槛反解 | 需多大雨、需多少排水能力 | p21/p22 反问题 |
| ⑤ 可信度 | 翻转带 + 三态标记 | p19/p20 + p32 决策卡 |

**第②步是全案的核心**：把"哪里水最深"（无法行动）换成"该用哪种手段"（可以行动）。

## 四、三个强调：扩展性 / 伦理 / 开放性

### 4.1 扩展性

| 维度 | 结论 | 证据 |
|---|---|---|
| 换城市 | ✅ 内核零改动可跑 | 郑州 9.3 s，守恒 7.02e-09（`gen_crosscity`） |
| 换事件 | ✅ 18 场 / 36 年 | p33 / p34 |
| 误差压缩 | ✅ 深度对幅度 **^0.434** | 雨量 ×10 → 深度 ×2.72 |
| 形状可用 | ✅ 越阈累计阈值跨度仅 **49.8%** | 22–33 mm；而时刻跨度 350% |
| 换降水类型 | ❌ **台风型可用（−8%），强对流不可用（峰值 −90%）** | `gen_crosscity` / `gen_convective` |
| 不透水率可迁移 | ✅ OSM+DEM 可推（均值 0.291 vs 标量 0.75） | p35；**对峰值影响仅 +0.0016 m（p36），已足够，不必再提精度** |
| **峰值判据的真实瓶颈** | **管网输水能力** | p36：系数 ×0.10 → 峰值 +0.879 m（其余通道合计 <0.002 m） |
| **水量账的真实瓶颈** | **土层容量** | p37：土层 30→600 mm，下渗占雨量 1.9% → 32.1%（峰值仅 −4.7%） |
| 峰值对土层是否稳健 | ✅ 稳健 | p37：20 倍土层只让峰值变 −4.7% |
| 透水化改造效果 | 🟡 有限 | p37 组合档 −10.2%，远小于管网通道 |

**扩展性的诚实边界是「降水类型」，不是「城市」。**

### 4.2 伦理

**证据不是我们说了什么，是我们放弃过什么：**

| 事件 | 处理 |
|---|---|
| ρ=0.72、p=0.004 的**有利结果** | 阈值敏感性不过 → 主动判"秩技能未确立"（p25） |
| 10 条断供记录 8 条域外 | 判 **FAIL**，不静默外推 |
| 28 个涝点 11 个域外 | 模型置空、标 `trust: 域外未计算` |
| 149 点监测网坐标未公开 | 标 `provenance: synthetic`，绝不冒充实测 |
| 27 条门槛 | **15 PASS / 5 FAIL / 7 BLOCKED** 全公开 |

**机制化而非自律化**：
工具层 R1 越域 / R2 弱基线 / R3 单口径 / R4 调用预算，
agent 门槛 G16 越界拒绝 100%、G17 弱基线拒绝 100%、G20 无证据声明 0/8。
**护栏在工具层，不在提示词层。**

### 4.3 开放性

| 项 | 状态 |
|---|---|
| 许可 | MIT + `NOTICE.md` 列第三方 |
| 复算 | 双指纹 `config_hash e464fea5962b` / `source_hash 40d07eb29407b4b6` |

## 五、借鉴 EWE（arXiv:2511.21444）

上海 AI Lab 2025-11 的 EWE 明确指出：**预测已饱和，自动化的诊断推理才是空白**。
这与本案定位一致——我们做的正是"诊断 + 决策"，不是"提升预报精度"。

### 5.1 我们已同构的部分

| EWE | 本案 |
|---|---|
| Knowledge-Enhanced Planning | 五步决策链 + 27 条门槛 |
| Closed-Loop Checker | R1–R4 护栏 + G16–G20 门槛 |
| Meteorological Toolkit | 守恒 / Green-Ampt / Manning 内核 + 反解 |

### 5.2 我们缺的一块：**Content Auditor**

EWE 的消融实验显示，检查"图是否清晰、标注是否遮挡"能让中尺度分析从 0.619 升到 0.680。
**我们产出 36 件产物，却从不检查可读性。** 这是可补的真缺口。

### 5.3 我们将借鉴的一条：**Step-wise evaluation**

EWE 不只看最终报告，而给每一步打分。我们的等价物是 G1–G27，但那是"全链一次体检"，
不是"逐步评估"。**可做"决策链逐步评估"**：分级对否 → 分型有据否 → 门槛可算否 → 可信度标出否。

## 八、参数优先级：实测排序（p36 / p37）

先把"哪个参数真正控制结论"测清楚，路标才有依据。

### 8.1 六通道敏感性（p36，烟花雨场 259 mm，基线峰值 0.4928 m）

| 通道 | 峰值水深 | 变化 |
|---|---|---|
| **A 管网输水系数 ×0.10** | **1.3720 m** | **+0.879 m（+178%）** |
| F 不透水率压导水率 | 0.4944 | +0.0016 |
| C 土壤容量 ×0.10 | 0.4938 | +0.0010 |
| D 地表糙率 ×2.0 | 0.4937 | +0.0009 |
| B 土壤导水率 ×0.10 | 0.4930 | +0.0002 |
| E 不透水率只压容量 | 0.4930 | +0.0002 |

**管网是压倒性主项，其影响是其余通道合计的数百倍。**

### 8.2 但土壤假设会不会推翻它？（p37，土层 30 → 600 mm）

| 土层容量 | 有效容量 | 峰值水深 | 下渗占雨量 |
|---|---|---|---|
| **30 mm（现状假设）** | 7.5 mm | 0.4928 | 1.9% |
| 300 mm | 75 mm | 0.4949 | 16.2% |
| **600 mm（真实包气带上限）** | 150 mm | **0.4695（−4.7%）** | **32.1%** |
| 600 mm + 不透水 0.291 | 425 mm | **0.4426（−10.2%）** | **54.0%** |

**结论：峰值判据对土层假设稳健**（20 倍土层只让峰值变 −4.7%），
**但水量账极敏感**（下渗占雨量 1.9% → 54%）。

> **成因**：150 mm 容量摊在 72 h 上只有约 2 mm/h，远低于峰值雨强 12+ mm/h。
> **峰值时刻土壤跟不上，所以土壤不控制峰值。**

**这一条修正了我此前的推测**：我曾说"若包气带取 1–2 m，土壤会变成主项"——
实测证否。土壤影响的是**水量分配与低雨量事件**，不是峰值。

### 8.3 实测得出的两条独立结论线

| 判据 | 控制项 | 敏感度 |
|---|---|---|
| **峰值水深 / 红橙格** | **管网输水能力** | 高（+178%） |
| **水量分配 / 下渗总量** | **土层容量** | 高（1.9% → 54%） |
| 不透水率 | 两者都弱 | 已足够，不必再提精度 |
| 地表糙率 | 两者都弱 | — |

**两条线要分开投资，不能互相替代。**

### 明确不做

| 不做 | 理由 |
|---|---|
| 优化 OSM 土地利用精度 | 不透水率影响仅 +0.0016 m（p36），已足够 |
| 继续优化幅度模型 | 已达 oracle **96.6%** |
| 追 3D/4D 求解器 | 瓶颈是分辨率与管网异质，不是维度 |
| 用土层假设推翻管网优先 | p37 实测：600 mm 下峰值仅 −4.7% |

### 一个必须先说清的前提

第 1 项与第 6 项**都依赖外部资料**（管网台账 / 土壤剖面）。
在拿到之前，能做的只有第 2、3、4 项——**产品形态与分辨率**。
这也决定了交付顺序：**先把产品形态做完，再等数据。**

## 十一、随案交付的口径声明

1. 观测水深为公开通报口径（5 处下立交统一 0.50 m，可能被取整）。
2. 分型来自模型自对照，不是实测归因。
3. 18 场共用宁波参数，Q 与面积的**绝对值**含共性偏差。
4. 面雨量为台风路径**参数化雨场**，非 ERA5 实测。
5. 分级阈值是本案件为横向比较设定的口径，**不是法定响应等级**。
6. 27 条门槛当前 **15 PASS / 5 FAIL / 7 BLOCKED**，逐条写明缺哪个外部读数。
