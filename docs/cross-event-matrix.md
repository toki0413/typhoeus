# 跨事件决策矩阵：18 场台风 / 36 年

时间 2026-10-17。产物 `out/p33_跨事件决策矩阵.json`，模块 `typhoeus/multievent_matrix.py`。

---

## 一、为什么要有这一件

此前所有诊断（p13 生命线、p17 归因、p25 排序、p32 决策卡）**全部锚在 2021 烟花单场**。
等于用一个事件定义产品——这是叙事错误，也是产品错误。

仓库里本来就有 **18 场跨 36 年（1990–2025）** 的批量结果，只是此前只用来标定
强度—损失斜率，没有当成**产品适用性的证据**。

## 二、结果：分级不依赖任何单一事件

### 2.1 18 场按功能损失分级

| 分级 | 场次 |
|---|---|
| 严重 | 3 |
| 较重 | 4 |
| 中等 | 3 |
| 轻微 | 1 |
| 无感 | 2 |

面雨量跨度 **2.2–291.6 mm**，残差占比全样本最大 **6.40%**（门槛 8，容差 20%）。
**每一场的水量守恒都闭合。**

### 2.2 烟花只是第 2 大，不是典型

| 排名 | 事件 | 面雨量 | Q_total |
|---|---|---|---|
| 1 | **1998 TODD** | 291.6 mm | **0.6069** |
| 2 | **2021 IN-FA（烟花）** | 202.5 mm | 0.4851 |
| 3 | 2014 FUNG-WONG | 121.6 mm | 0.2447 |

> 烟花既不是最大场次，也不是典型场次。**用单场定义产品，会同时高估与低估其他场次。**

### 2.3 跨事件强度—损失关系：ρ = 0.9945

| 项 | 值 |
|---|---|
| Spearman ρ | **0.9945** |
| 样本 | 13（致涝场次） |
| 严格单调违背 | **1 处** |

那一处违背必须写出来，不能只说"基本单调"：

```
1995 JANIS（69.2 mm，Q=0.1478） → 2000 KAI-TAK（73.5 mm，Q=0.1475）
Q 降幅 0.000300
```

**降幅 3e-4，属量化误差量级，不构成机制性违背。**

### 2.4 一处上游口径不一致，已解释

上游 `样本` 声明致涝 **14** 场，按 `状态==致涝` 筛得 **13** 场。差的那一场是：

```
1990 ABE：面雨量 4.6 mm，峰值水深 0.171 m，Q = 0.0000
```

**有积水，但功能损失为零**（该处无承灾体暴露），故状态标为未致涝。
本件按 Q 分级，它落在"无感"档——**两种口径对分级无影响，但数字差必须写明**。

## 三、这条与 p25 的失败不是同一件事

这一点必须切开，否则会被当成自相矛盾：

| | p25 序数技能 | 本件 |
|---|---|---|
| 样本单位 | **涝点**（17 个） | **台风事件**（13–18 场） |
| 问的问题 | 哪些点更严重、先修哪个 | 雨大时损失是否更大 |
| 结果 | ❌ 秩技能未确立 | ✅ ρ=0.9945 |

**跨事件成立，不能推出跨涝点排序可放宽。**
这是两种完全不同的排序能力：前者比的是"不同雨量下同一片区的损失"，
后者比的是"同一场雨下不同点位的严重度"。

## 四、对叙事的三点直接修正

1. **产品不是"烟花模型"**，而是"给定面雨量 → 分级 → 动作"的链条，
   已在 18 场跨 36 年上连续产出分级分布。
2. **不要再拿 2021 当主场景**。可以拿它当**验证案例之一**，
   主场景应表述为"持续 36 年的台风序列"。
3. **不要再用"烟花事件"当量词**。规格里写"每场事件 72 h 情景"，
   而不是"烟花 72 h 情景"。

## 五、还差什么（诚实清单）

| 缺口 | 说明 |
|---|---|
| 逐场四色面积 | 需逐场重跑内核（18 × 6 s ≈ 2 min），本件未做，故不给淹没面积 |
| 逐场分型 | 每场需 3 次附加内核（排水归零/增强/对照），约 54 次运行，未做 |
| 参数逐场重标 | 18 场共用一套宁波参数，故 Q 的**绝对值**含共性偏差；排名与单调性比绝对值可靠 |
| 面雨量来源 | 台风路径**参数化雨场**，非 ERA5 实测；口径限制见产物 `降雨口径` 段 |

## 六、边界

1. 分级阈值（Q 的五个区间）是本件为**横向比较**设定的口径，**不是法定响应等级**；
   法定等级须由地方预案确定。
2. 18 场未逐场重标本地方参数，故不宣称绝对损失量准确。
3. 事件目录来自项目 `EVENT_CATALOG`，覆盖 1990–2025，不含 2026 年场次。
4. 单调性检验是**样本内**的；未见场次（如未来台风）不保证仍单调。
