# WIS 2.0 能用上吗

时间 2026-10-17。结论先行：**方向上对，但对我们当前缺口帮助有限；
它真正的价值不在数据本身，而在一条可以引用的政策依据。**

---

## 一、WIS 2.0 是什么

WMO 信息系统 2.0（WIS 2.0）是 WMO 的下一代数据交换框架，替代沿用数十年的 GTS。
三个核心组件：

| 组件 | 作用 | 技术 |
|---|---|---|
| **Global Discovery Catalogue (GDC)** | 元数据检索 | WCMP2 元数据 / OGC API - Records |
| **Global Broker (GB)** | 实时消息通知 | **MQTT** |
| **Global Cache (GC)** | 数据文件下载 | HTTPS |

配套的政策文件是 **WMO Unified Data Policy（第 1 号决议，2021）**，
确立"核心数据应**免费、无限制**交换"的原则。

## 二、实测：本机无法确认可达性（不是"不可用"，是"没验成"）

| 主机 | DNS 解析 |
|---|---|
| `www.wmo.int` | ✅ |
| `community.wmo.int` | ✅ |
| `library.wmo.int` | ✅ |
| `open-meteo.com`（对照） | ✅ |
| `nonexistent-xyz-9f3a.wmo.int`（故意乱写，对照） | ❌ gaierror |
| **`wis2globalcatalogue.wmo.int`** | ❌ **与乱写主机表现完全一致** |
| `wis2globalbroker.wmo.int` / `wis2globalcache.wmo.int` | ❌ 同上 |
| `wis2box.wis.wmo.int` 系列 | ❌ 同上 |

**判读**：`www`/`community`/`library` 都能解析，说明不是本机网络整体故障；
而所有 `wis2*` 主机名与故意乱写的主机表现相同——
**说明我猜的这组公开主机名在公网 DNS 中不存在（或已改名）**。

> **我不编造可达性。** 这一条只能记作"未验证"，不能记作"不可用"。

---

## 三、即使接上，它能给我们什么

必须分清一件事：**WIS 2.0 交换的是"全球交换子集"，不是各国完整观测网。**

| 数据类型 | 在 WIS 2.0 里 | 对我们的用途 |
|---|---|---|
| **SYNOP** 地面天气报告 | ✅ 有，但只含各会员**纳入全球交换的那部分站** | 🟡 中国境内可能仅数站，未必覆盖宁波 |
| **TEMP** 探空 | ✅ 有 | ❌ 与城市内涝无关 |
| BUOY / 船舶 | ✅ 有 | ❌ 内陆城市无关 |
| 卫星产品 | ✅ 部分 | 🟡 分辨率与频率不足以抓对流核心 |
| **NWP 产品（GRIB）** | ✅ 有 | ❌ 我们已有 Open-Meteo，重复 |
| **雷达 QPE** | ❌ 不在 | ❌ **这正是我们最缺的** |
| **城市内涝监测点** | ❌ 不在 | ❌ **149 点台账不在** |
| **河网水位** | ❌ 不在 | ❌ **顶托（×2.81 主控）不在** |

**关键判断**：全球交换站网是**为数值天气预报选定的基准子集**（历史上是 RBSN/GTS 选站），
**不是各国监测网的镜像**。所以它天然不含城市尺度的加密观测。

> **WIS 2.0 解决的是"国与国之间交换"，不是"城市内部观测"。**
> 而我们的缺口全部在城市尺度以下。

---

## 四、它真正的价值：一条可引用的政策依据

这是本件最有用的一条。

我们要不到数据的真实原因，常常不是"文件没找到"，而是**对方没有开放义务的明确依据**。
WMO 统一数据政策提供了一条：

> **《WMO Unified Data Policy》（Resolution 1, 2021）确立核心数据免费、
> 无限制交换原则；WIS 2.0 是该政策的技术实现。**

所以对接省气象局 / 市气象局时，可以这样提：

> 「贵局作为 WMO 会员，按统一数据政策，核心数据（含地面观测、雷达基数据）
> 属于免费无限制交换范畴。我们申请的是**城市尺度加密观测**，
> 属于超出全球交换子集的部分，愿意按数据共享协议办理。」

**这句话的作用不是强制，而是把"要不要给"变成"按什么程序给"**——
两者对推进合作的难易度完全不同。

---

## 五、判定

| 选项 | 判定 |
|---|---|
| 把 WIS 2.0 接成数据源 | ❌ **不做**（本机未验证可达；且不含我们的缺口） |
| 为它改造产品 | ❌ 不做 |
| **在数据申请话术里引用 WMO 统一数据政策** | ✅ **值得**（零成本，改变谈判性质） |
| 持续跟踪 WIS 2.0 的中国节点 | 🟡 观察（若 CMA 上线 WIS2 节点并开放雷达，才真正有用） |

### 一句话

> **WIS 2.0 是"国与国之间交换观测"的管道，我们的缺口在"城市内部"，
> 两者不在同一层。**
> 但它背后的**统一数据政策**可以当作索取数据的依据——
> 这比它的技术接口对我们更有用。

---

## 六、边界

1. **本机未能验证 WIS 2.0 任何组件的可达性**——所有 `wis2*` 主机名 DNS 失败，
   与故意乱写的主机表现一致。这不等于它不存在，只等于"我没找到正确地址"。
2. 上表中"WIS 2.0 有什么/没什么"依据的是其架构设计与全球交换惯例，
   **未逐项在线核实**。
3. 全球交换站网的具体规模随时间与会员政策变化，文中不给站数。
4. WMO 统一数据政策的条文细节未逐条核对原文；引用时应回到
   Resolution 1 (Cg-18, 2021) 原文。
5. 本件为**概念与可达性评估**，不产生新产物，不进本次提交材料。
