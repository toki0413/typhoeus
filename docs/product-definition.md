# 提比翁 · 产品定义（情景—规划机）

时间 2026-10-16。性质：**产品定义**，供对外叙事与施工共用。
计量口径：凡标「实测」者均为工作区可复算；凡标「材料说」者为仓内自述且本次无法独立核实。

---

## 1. 一句话定义

> **提比翁是一台"情景—规划机"：给定一个台风情景，回答三件事——哪些点名设施会失能、片区功能损失多少、按什么次序恢复与投哪一档能降多少；每件都带误差带与"不可主张项"。**

**它不是**：实时预报系统、预警发布系统、定级系统、调度系统、单点水深产品。

**它做预测的方式是"条件预测"**：不预测明天，预测"**如果来的是 p90 量级**"会发生什么。

## 2. 为什么不做复盘、也不做实时预报

| 层 | 含义 | 数据要求 | 实测状态 | 处置 |
|---|---|---|---|---|
| A 回溯标定 | 用 2021 烟花校准模型 | 历史再分析＋台账 | ✅ 有（命中 0%、MAE 0.359 m） | **降为标定证据，不作产品** |
| **B 情景前瞻** | "如果来 X 量级会怎样" | 台风路径库＋参数化雨场＋分位数带 | ✅ **有真材料**：IBTrACS 238 MB、目录 18 场/实算 16 场、跨 36 年、分位数 p50/p80/p90/p95、强度—损失斜率 2.109（R² 0.883，n=14） | **产品主体** |
| C 实时预报 | 明天几点、哪条路 | 雷达 / CMFD / IMERG 实时流 | ⛔ 无（ERA5 为再分析；峰值雨强 6.12 mm/h，仅为参数化场的 1/3） | **不主张**；入口接入见 §7 |

**理由**：C 层本地竞品已用 X 波段双偏振相控阵雷达＋变分同化做到 100 m×1 min、分钟级响应；B 层竞品**没有**跨 36 年一致标定与可复算分位数。**在 B 层竞争，不在 C 层竞争。**

## 4. 产品功能（三件产物）

### ① 情景阈值表（腿一）
- **回答**：给定 72 h 面雨量情景（p50 / p80 / p90 / p95），哪些点名设施越过已发布致灾阈值。
- **盘上材料**：28 条点名涝点（含结构类型、实测水深、坐标精度 ±100 m）；分位数带 p50 258.4 / p80 313.2 / p90 338.8 / p95 354.1 mm。
- **边界（写死在件上）**：只做对照与记录，**不改写等级**；474 处隐患点阈值表的原始文件本地未检索到，属出处未定级。

### ② 情景损失单（腿二）
- **回答**：该情景下的片区功能损失总量与形状、四色面积构成、事件后四项加法分解。
- **盘上材料（实测）**：
  - 强度—损失关系：`Q = exp(−11.146) × 雨量^2.109`，R² 0.8833，n=14，单调违背 0 处
  - **斜率含义**：面雨量翻倍 → 功能损失增 **4.3 倍**（超线性有实测支撑）
  - 四项闭合：气候 / 超标 / 工程失效 / 残差，残差占比 **10.0%**（容差 20%）
  - 稳健性：参数族扫描峰值水深 **0.205–1.367 m**（带宽 15.8%）
- **边界**：**片区级可主张，单点级不主张**（模型在 17 个域内涝点中 12 个静默，偏差 17/17 全为负）。

### ③ 方案比选件（腿二→腿三）
- **回答**：两个候选方案（如"布点 12 处"vs"集中改造 3 个下穿立交"）的成本—损失下降对照。
- **盘上材料**：建议布点数 **12**、空间覆盖率 0.239；韧性价目表三档（Ⅰ级 2–5 万/点位、Ⅱ级 300–800 万/片区、Ⅲ级 800–2000 万/站）；对应减少功能损失 1% / 8% / 15%。
- **边界**：**收益侧未标定**（门槛 10 BLOCKED：改造前后观测完全缺失）；价目表自述"量级估算，不作报价依据"。件上必须逐条标注。

## 8. 技术路线参考：Tadpole（3D PDE 基础模型）

来源：[Tadpole: Autoencoders as Foundation Models for 3D PDEs with Online Learning](https://arxiv.org/abs/2605.15284)（Liu / Koehler / Holzschuh / Thuerey，TUM，arXiv:2605.15284v1，2026-05-14；作者组为 PDE 基础模型方向既有团队）。
**性质：方法学参考，非本项目已实现能力。** 论文给出的代码地址 `https://github.com/tum-pbs/tadpole` 本次抓取失败，代码与权重的实际可用状态**未经核实**。

### 8.1 它的三个核心做法（论文自述）

| 做法 | 内容 |
|---|---|
| 重建预训练而非动力学预训练 | 预训练目标是自编码**重构 u_t**，非预测 u_{t+Δt}；论文理由：动力学映射要在解流形上再学一个非线性流，比重构难得多 |
| 在线生成数据 | 预训练数据**不落盘**，由 PyTorch GPU 伪谱求解器（FFT 空间导数 + ETDRK 时间积分）训练时实时生成，等价 **202 TB** 数据；三阶段缓冲（FIFO→FIFO→MFU 缓存）把仿真延迟藏在训练算力后 |
| 单通道裁剪 + 平移等变 | [B,C,X,Y,Z] 的通道维折进 batch，随机取 **64³ 单通道 crop**；冻结卷积层可处理与训练不同尺寸输入。下游 Tadpole-DFT：潜空间变换子网络 + 重接 skip（零初始化 γ）+ **LoRA**，骨干冻结 |

规模：7 个 PDE 系统 × 4 分辨率（64³–384³）；S/B/L = 8.8M / 38.1M / 152.1M 参数；重构 RMSE 5.48e-3 / 2.83e-3 / 2.06e-3；零样本可上 1024³。

### 8.2 可借鉴四条（按对本项目的价值排序）

| # | 可借鉴 | 对本项目的作用 |
|---|---|---|
| R1 | **在线/合成数据生成** | 直接命中最大约束——本仓 16 场事件跨 36 年、超阈值点仅 7 个（GPD 不可用，需 n≥30）。做法：用**自己的参数化雨场 + 图守恒律内核**当数据发生器，把现有降级路径 `parametric-fallback` 从"兜底"升为"情景发生器" |
| R2 | **只学表示 + LoRA 微调** | 此前把 AI 降尺度排在最后，理由是"8 站 × 1 场做不出可信模型"——该判断对**全参数训练**成立；此路线下只需冻结表示层、微调低秩增量，样本需求下降一个量级 |
| R3 | **潜空间代理** | 规划岗要的是参数扫描与误差带（现值靠反复跑内核，27 s/次，扫 9 组即数分钟）。代理把单次评估压到秒级，误差带与方案比选才可能交互化——这是"情景—规划机"最缺的一环 |
| R4 | **把能力边界写进架构** | 论文只用重构目标预训练、并移除全部 PDE 参数嵌入，边界写在架构里而非免责声明里。与本项目"三态判定 / 拒答"同源，可作方法学依据引用 |

### 8.3 不适用与必须设防三条

| 项 | 问题 |
|---|---|
| **不保证守恒** | 它是数据驱动的表示学习，**不保证质量守恒、正性、单调性**。本项目三条硬约束是高风险决策的立身之本——若用潜空间代理，**代理只能当"候选生成器"，输出必须过守恒投影与三态判定**（与 `COMPOUND_RISK_PLAN.md` §2.3"AI 不用在守恒上"一致） |
| **维度与范式不匹配** | 论文为 **3D** PDE（[B,C,X,Y,Z]，1024³ 级）；本项目为 **2D 浅水 + 降雨外强迫**（144×270 = 38,880 格）。64³ crop 策略在此规模意义有限；降雨是外强迫而非状态变量，与"单通道重构"范式不同构 |
| **不解决精度根因** | 命中率 0% 的根因是管网顶托缺失 + 30 m DSM 无法表达下穿凹陷 + 峰值雨强仅参数化场的 1/3（ERA5 6.12 vs 16.43 mm/h）。该路线**不补管网台账**，不作为精度解药 |

### 8.4 落地方案与判据

```
① 情景发生器：参数化雨场批量生成 N 个情景（现有路径）
② 伪真值    ：每情景跑一次内核，存「降雨场 → 峰值水深 / 功能损失」
③ 表示学习  ：照 Tadpole 只学重构（不解动力学），输入单通道裁剪
④ 下游      ：LoRA + 潜空间变换微调，学「降雨强迫 → 损失场」
⑤ 出口闸    ：代理输出过守恒投影 + 三态判定，不过则拒发
```

**判据（必须先写定，否则重演"说不出比基线好在哪"）**：
> 代理与内核在留出情景上的偏差 **≤ 内核自身的参数族带宽（实测 15.8%，峰值水深 0.205–1.367 m）**；若代理偏差大于该带宽，代理无价值——**如实报告并停用**。

该判据与 SAR 那条纪律同源（"打不过 Otsu 基线就停在这里"），是本项目可信度的组成部分，不是形式。
