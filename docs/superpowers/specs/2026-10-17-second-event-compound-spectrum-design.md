# 设计：第二事件深挖（梅花替代菲特）+ 一页正文复合全谱升维

时间 2026-10-17。目标赛事 AI4Climate 2026（截止 2026-10-19 24:00）。

## 背景与动机

用户评审 `submission/01_一页正文.md` 后判断"太狭隘"：叙事锚死在宁波·烟花单事件、

## 关键事实核查（已验证）

- **菲特（2013）物理不可行**：本地 IBTrACS 65 个路径点，最近距计算域中心
  327 km；轨迹最北 27.1°N，未达计算域纬度 29.88°N；重灾区余姚在计算域
  bbox（121.55–121.7E / 29.84–29.92N）之外。参数化雨场必为零。放弃。
- **梅花（MUIFA 2022）是最佳替代**：
  - 批量框架已实算成功：`out/07_multievent_calibration.json` 场次明细中
    72h 面雨量 40.7 mm、峰值水深 0.488 m、Q_total 0.0703、残差闭合——
    18 场中仅次于烟花（202.5 mm / Q 0.4851）；
  - ERA5 历史场 2022 实测可取（multievent 模块文档：1998/2014/2022/2025
    四场全部返回实值）→ 可做 ERA5 驱动 + 参数化对照的双口径；
  - 2022-09 梅花过境宁波，存在公开通报可检索对照材料。

## 设计一：梅花全链深挖

用与烟花相同的五步决策链（分级→找病因→定手段→算门槛→标可信度）跑梅花：

1. **降雨双口径**：ERA5 再分析驱动 + 参数化对照（同烟花方法学）。
2. **产物**：梅花场的决策卡（p17 分型 / p20 翻转带 / p21-p22 反解门槛 /
   可信度标记），与烟花同构的逐列对比表。
3. **公开通报对照**：检索梅花宁波段积水/断供通报；有则定性对照写入，
   无则该格标 BLOCKED 并写明缺什么。
4. **诚实边界（写死）**：
   - 梅花无 28 点实测台账 → 证明"链条在场次间可迁移"，**不主张精度迁移**；
   - 批量参数化雨量 40.7 mm 与通报量级差异须按口径写明（参数化 vs 实测锚）。

## 设计二：一页正文 v2（复合气候风险全谱升维）

主框架改为"**一场台风 = 风、雨、潮、涝四灾种叠加**"，三层任务链贯穿：

```
识别（μ_t / 四档分级）→ 评估（Q / 归因 / 生命线）→ 转译（决策卡 / 涝点卡）
```

- **三态标格**（每层带可判定口径）：
  - 雨-涝链：PASS（烟花 32 件产物 + 18 场批量 + 梅花深挖）；
  - 潮-顶托：BLOCKED——已诊断（涝点比河网高 5.63 m，5/17 点可能受顶托），
    缺宁波市"河网水位"应用的逐时数据接口；
  - 风灾：**未接入内核**，明示不在当前能力内，不假装；
  - 生命线：p13 断供预判已有实测对照（10 条通报）。
- **可迁移证据进场**：18 场批量标定（强度-损失 R²=0.88、跨 2.2–291.6 mm
  共 130 倍雨量离散）+ 梅花深挖。
- **赛道映射表一张**：三层任务链 ↔ 三条腿 ↔ 既有产物。
- 所有已有数字照旧；不新增未验证声称；../../analysis/CONTEXT.md 三态文化不放宽。
