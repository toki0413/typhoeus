# 台风暴雨下的碳，以及碳价与韧性的真实联系

时间 2026-10-17。产物 `out/p45_碳水耦合.json`，模块 `typhoeus/carbon_water.py`。

回答两个问题：
① 台风暴雨下"碳"资源怎么变？
② 城市韧性与碳定价之间是否有联系？

---

## 一、先立一个物理基础：85.4% 的雨量走排水管网

实测（烟花 259 mm，一次内核的水量账）：

| 路径 | 万 m³ | 占降雨 |
|---|---|---|
| 降雨 | 2896.7 | 100% |
| **排水（管网）** | **2473.3** | **85.4%** |
| 域内存量（积水） | 186.2 | 6.4% |
| 边界出流 | 113.2 | 3.9% |
| 下渗（土壤） | 54.0 | 1.9% |

**这一个数同时解释了两件此前分别测出的事**：
- p36/p44 为什么"排水能力是压倒性主控"——**因为它是水的唯一主出口**
- 碳为什么与该系统强耦合——**因为它也是碳的唯一主通道**

> 换句话说：**在这个模型里，水与碳走同一条路。**
> 这不是巧合，是城市集中排水体制的定义性特征。

## 二、问题①：暴雨下的碳怎么变

### 2.1 主通道：合流制溢流（CSO）

雨污合流的城市，暴雨时污水与雨水一起溢流进河网，伴随 **CH₄** 与 **N₂O** 释放
（管网内厌氧段产甲烷，溢流口释放）。

排水量 2473.3 万 m³ × 排放因子 → 碳通量：

| 排放因子 | CH₄ | CO₂e（GWP100=28） |
|---|---|---|
| 1 g/m³ | 24.7 t | **692 t** |
| 5 g/m³ | 123.7 t | **3 463 t** |
| 20 g/m³ | 494.7 t | **13 851 t** |
| 50 g/m³ | 1 236.7 t | **34 627 t** |

**区间跨 50 倍。这就是为什么不能给点值。**

排放因子（g CH₄ / m³ 排水）是本件**唯一的文献假设**，实测报道从个位数到
数十 g/m³ 不等，随温度、停留时间、管内厌氧程度强烈变化。
**按参数处理，不按取值处理。**

### 2.2 次通道：应急响应能耗 —— 可忽略

100 台泵 × 50 kW × 16 h = 8 万 kWh → **约 64 tCO₂**。

比排水通道小 **2–3 个数量级**。

> **不要在这上面找故事。** 它是真的小。
> （这一条值得写下来，因为"应急响应高碳"是个容易讲的漂亮说法，但数据不支持。）

### 2.3 第三通道：绿地碳汇受损 —— 更小

按 p29 的 422.4 ha 公共空间，年固碳约 1 267 tCO₂/yr，
即使全部因灾损失一年，也只有千吨量级——与 2.1 的中位档同量级但更不确定。

## 三、问题②：碳价与韧性的联系——存在，但不是我们以为的那种

### 3.1 不是"用碳价给洪灾标价"

那是把碳定价当成外挂的货币化工具，且需要排放-损害全链（我们只有最后一环）。

### 3.2 而是"碳价轻微地改变方案优劣"

绿方案（调蓄滞留）能减少排水量：

| 项 | 值 |
|---|---|
| 灰方案排水 | 2 473.3 万 m³ |
| 绿方案滞留（p29 实测 422.4 ha × 0.3 m） | 126.7 万 m³ |
| **只减少 5.1%** | |

在碳价四档下：

| 碳价 ¥/tCO₂e | 灰方案碳成本 | 绿方案碳成本 | 绿方案节省 |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| **100**（中国碳市场） | 138.5 万 | 131.4 万 | **7.1 万** |
| **370**（SCC 量级） | 512.5 万 | 486.2 万 | **26.3 万** |
| **1000**（高位情景） | 1 385.1 万 | 1 314.1 万 | **71.0 万** |

### 3.3 关键判据：不足以翻转比选

调蓄改造投资是**百万–千万级**，而碳价即使到 ¥1000/t 也只能节省 **71 万元**。

> **碳价是加分项，不是决定项。**

### 3.4 但这个结果揭示了一个更重要的事

**调蓄只覆盖 5.1% 的排水量**，所以它对碳的贡献天然有限。

> **碳减排不可能靠"错峰调蓄"，只能靠减少总排水量**——
> 即**源头减排**（透水铺装、下凹绿地、雨水花园减少径流系数），
> 或**截污**（把合流制改成雨污分流，从根上不产生 CSO）。

**这两条恰好都不是"韧性"的常规工具，而是"减排"的常规工具。**

于是联系的真实形态浮出来了：

| | 提升城市韧性 | 减少暴雨碳排 |
|---|---|---|
| 主手段 | 管网扩容 + 调蓄 | **源头减排 / 雨污分流** |
| 对 85.4% 排水通道 | 加大通过能力 | **减少进入量** |
| 对碳 | 微弱（5%） | 直接 |

> **碳定价与韧性的联系，不是"碳价补贴韧性"，
> 而是"两者共用同一个通道，但推的方向相反"：**
> 韧性要**排得出去**，减排要**不被排出去**。
> 碳价提高时，这个张力会变大——**这才是真正值得写进产品的东西**。

## 四、对产品的处置

| 选项 | 判定 |
|---|---|
| 把碳价写进主线定位 | ❌ 不做（因果链不全，且量级不足） |
| 把碳价做成**可调参数**并入 p3 方案比选 | ✅ 可做（默认 0，预设 ¥100 / ¥370 两档） |
| 宣称碳价会改变结论 | ❌ 不做（¥1000/t 也只省 71 万） |
| **把"排水-排放同通道"写成产品的一条认知** | ✅ **最值得** |
| 加"源头减排/雨污分流"作为第五类手段 | ✅ 可做（当前分型只有保运行/加管径/调蓄/补几何） |

### 一句话

> **在这个系统里，水与碳走同一条路——85.4% 的雨量穿过管网。**
> 所以碳价能影响排水决策，但幅度有限（千吨级碳、百万元级成本）；
> **它真正提醒我们的是：韧性与减排在同一个通道上推相反的方向。**
> 加管网让水更快出去，减碳让水不要进来。规划必须同时看这两头。

## 五、边界

1. **排放因子是本件唯一的关键假设，区间 50 倍**。任何碳通量数字都必须带区间引用。
2. GWP100(CH₄)=28 取 IPCC AR6 量级；若用 GWP20（约 80），短时窗碳代价高约 3 倍。
3. 未计入 N₂O（GWP 273）；若计入，碳通量再上升。
4. 绿方案"滞留 = 减少排水"是**上限估计**：真实系统中滞留水终将排出，只是错峰，
   故实际减排量被高估。
5. 应急响应能耗为量级估算（100 台泵 × 50 kW × 16 h），非实测。
6. 共用宁波参数；碳价四档为情景，非预测。
7. **本件不进本次提交材料**（技术冻结），是概念澄清与下一版输入。
