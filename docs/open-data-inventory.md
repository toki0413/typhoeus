# 开源数据集/语料集：按杠杆排序的清点

时间 2026-10-17。方法：**按 p44 实测的杠杆排序去找**，不按"能搜到什么"。
每条都实测可达性（HTTP 状态、返回内容）。

---

## 一、结论先行

| 缺口 | 杠杆 | 开源可得性 | 判定 |
|---|---|---|---|
| **城建排水（顶托/管网）** | **×2.81** | ❌ **无可用的开源数据** | **必须靠合作** |
| 降雨集中度（雷达 QPE） | ×1.64 | 🟡 全球有、中国无 | 半通 |
| 降雨总量 | ×1.19 | ✅ 已有（Open-Meteo） | 通 |
| 不透水率 / 建成区 | ×1.01 | ✅ **GHSL built-up（新发现）** | 通 |
| 人口暴露 | 未测 | ✅ **WorldPop（新发现）** | 通 |
| 土壤 | ×1.01（峰值）/ 17×（水量账） | ❌ SoilGrids 对中国返回 null | 断 |
| 潮位（顶托驱动） | 归入 ×2.81 | ❌ **SLSMF 中国仅 3 站，浙江无** | 断 |

> **最要紧的一句话**：
> **杠杆最大的那个缺口（城建排水 ×2.81），没有任何开源数据集能补。**
> 这不是没找够——是这类数据在制度上就不公开。所以它只能靠合作，
> 而**河网水位已有公开通道（浙江水雨情平台，见 `official-data-sources.md` §7）**，
> 这是目前唯一可能撬动这条轴的入口。

## 二、新找到的两个可用源

### 2.1 GHSL 建成区表面比例（JRC，免注册）

**GHS_BUILT_S_GLOBE_R2023A** —— 建成区表面比例（built-up surface fraction），全球覆盖。

| 项 | 内容 |
|---|---|
| 纪元 | **1975 – 2030，逐期**（含 2020、2025、2030） |
| 分辨率 | 3 角秒（≈90 m）/ 30 角秒 / 100 m / 1000 m |
| 投影 | **EPSG:4326** 与 Mollweide 两种 |
| 许可 | 开放（JRC），需署名 |
| 实测 | `/GHS_BUILT_S_GLOBE_R2023A/GHS_BUILT_S_E2020_GLOBE_R2023A_4326_3ss/V1-0/` 下 3.2 GB 全球 zip，HTTP 200 可下；另有 `tiles/` 分块 |

**为什么有用**：
1. 比 OSM **覆盖完整**（OSM 在城乡结合部有缺口，会低估硬化）
2. **多期**——可直接给出"城市化进程"，这正好接上更早提过的
   "土壤/下垫面演变"那条线（此前判为不可测，因为只有 2021–2024 的事件目录；
   但 GHSL 给的是**下垫面本身的时间序列**，与事件目录缺的时间序列是两件事）
3. 对任何城市都可用，**提升跨城市泛化**

**但必须承认**：按 p36/p44，不透水率对峰值的杠杆只有 **+0.0016 m（×1.01）**。
所以它**不解决主要矛盾**，只是让一个已知不敏感的参数更准。

### 2.2 WorldPop 人口分布（免注册）

| 项 | 内容 |
|---|---|
| 接口 | `https://hub.worldpop.org/rest/data/pop/wpgp` |
| 实测 | HTTP 200，**5221 条**，按 `iso3` 与 `popyear` 索引，含 CHN |
| 分辨率 | 100 m（部分 1 km） |
| 许可 | CC BY 4.0 |

**为什么有用**：我们算的是**功能损失 Q**（无量纲），从未连到**人口暴露**。
高风险应用条款要求"风险影响"，人口暴露是最直接的量化。
这也是"向平民发布早期预警"那句话唯一能落地的量化支撑。

## 三、确认不可用的（避免下次重复试）

| 源 | 实测结果 | 说明 |
|---|---|---|
| **SoilGrids（ISRIC）** | 美国 Kansas 有值（clay=359），**荷兰 / 巴西 / 中国宁波全为 null** | 公共端点**非全球覆盖**，对中国不可用 |
| **SLSMF（IOC 海平面）** | 全球 1959 站，**中国仅 3 站**（清澜、深圳、闸坡）；宁波 250 km 内**0 站** | 中国不向该网络报数 |
| HydroWeb | TLS 证书校验失败 | 未进一步尝试 |
| IMERG / GPM | 需 NASA Earthdata（本项目已判定不可用） | 历史结论不变 |
| 中国雷达 QPE | 需中国气象局实名 | 未接 |

## 四、语料（文本）方面

我们已有的语料用途是 **信息时滞（p16）**：从公开通报里提取"何时说了什么"。
可扩展的公开文本源：

| 源 | 内容 | 可达性 |
|---|---|---|
| 应急管理部 / 省市应急厅网站 | 响应启动、转移、封道通报 | 公开（已用） |
| 中国气象局 / 中央气象台 | 预警信号发布时刻 | 公开（已用） |
| 央广网、中新网等 | 现场灾情（水深、被困） | 公开（已用） |
| 台风网社区帖（topic 5152） | 参赛数据源汇总 | 已抓 |
| GDACS | 全球灾害警报（结构化） | 未测 |

**语料的天花板**：通报是**离散事件**，不是连续序列。所以它能定"何时说了"，
不能定"水位如何逐时变化"——这与 p24 的 13 条时间线口径一致。

## 五、该怎么用这份清点

| 动作 | 依据 |
|---|---|
| **不再花时间找管网/潮位开源数据** | 已确认无（SLSMF 3 站、管网无） |
| 河网水位只走**浙江水雨情平台**这一条 | 唯一公开通道，已有接口（`official-data-sources.md` §7） |
| GHSL built-up 列入**下一版**（提升跨城市泛化，非解决主矛盾） | 可下、多期、全球 |
| WorldPop 列入**下一版**（补人口暴露） | 可下、含 CHN |
| 土壤维持 30 mm 假设并**明示未标定** | SoilGrids 对中国不可用；p37 证明峰值对它稳健 |

## 六、边界

1. 本清点只测**可达性**，未做数据质量核验（未下载 GHSL 3.2 GB 验证）。
2. SoilGrids 的 null 可能是**端点限流或临时不可用**，不排除换镜像后可用。
3. GHSL 与 WorldPop 的许可要求署名，未做法务审阅。
4. 本件是**数据侦察**，不是新产物；技术冻结仍然有效，不进本次提交材料。
5. 杠杆数值来自 p44，基线为 p90 / C1 / 30 mm / 0.05 m；换基线后排序可能变化。
