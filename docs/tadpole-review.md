# Tadpole 借鉴评估

论文：*Tadpole: Autoencoders as Foundation Models for 3D PDEs with Online Learning*
Qiang Liu, Felix Koehler, Benjamin Holzschuh, Nils Thuerey（TUM）
[arXiv:2605.15284](https://arxiv.org/abs/2605.15284) · [代码](https://github.com/tum-pbs/tadpole) · NeurIPS 2026

评估时间 2026-10-17。本文档记录**可借鉴项、已实测的收益、以及不适用项**。

---

## 1. 论文的三个核心设计

| 设计 | 内容 | 关键论点 |
|---|---|---|
| **重建式预训练** | 预训练为 VAE + 对抗损失，只做重建，不做动力学 | 学"解空间的流形"比学"流形上的流"容易；重建还能支撑多种下游任务 |
| **在线数据生成** | GPU 伪谱求解器即时生成 + 三级 FIFO/MFU 缓冲，等效 **202 TB**，比离线快 1.8× | 3D PDE 数据的存储与 I/O 才是规模瓶颈，不是算力 |
| **Tadpole-DFT 微调** | 潜空间子网 S + **重新接回的 skip connection（零初始化 γ）** + LoRA | 纯潜空间动力学不够准，必须把高分辨率细节接回来 |

**第三条是本文对我们最有价值的部分。**

## 2. 与本项目的映射：A' 就是"砍掉 skip 的 Tadpole-DFT"

我们刚跑出的路线 A'：

```
h(t, x) = a(t) · h_peak(x)
```

这是一个**秩 1 分解**：只有瓶颈（幅度标量 a(t)）加一个固定空间模板。
**它在结构上等价于"只保留潜变量、丢弃 skip connection"** —— 正是 Tadpole 指出的不够准的形态。

Tadpole 的解法（零初始化 γ 的 skip connection）翻译到我们的记号就是：

```
h(t, x) = a(t) · h_peak(x) + γ · Σ_k c_k(t) · φ_k(x)
```

- `φ_k`：从残差得到的**共享空间基**
- `c_k(t)`：由雨特征预测的系数
- `γ`：零初始化 ⇒ **k=0 时严格退化为 A'**，训练只会在其上做增量

我们按这个形式实现了 **A''**。

## 3. 实测：A'' 几乎抹平了与 oracle 的差距

60 场情景，留出 12 场；残差基 k=8，解释残差能量 **72.1%**。

| 指标 | A' | **A''** | oracle 上界 | A'' 距 oracle |
|---|---|---|---|---|
| 全局 NMSE | 0.0125 | **0.0096** | 0.0094 | +0.0002（97.9%） |
| **深处 1% 格点 NMSE** | 0.0250 | **0.0201** | 0.0202 | +0.0001（99.5%） |

**A' → A''：全局误差降 23%，深处格点误差降 20%。**

### 3.1 为什么必须同时看"深处 1% 格点"

全局 NMSE 由**大面积浅水**主导，而台账上会报的涝点是**最深处那 1% 格点**。
若只盯全局 NMSE，接不接回残差基几乎看不出差别（0.0125 → 0.0096 看起来是"小改善"）；
换成深处 1% 口径，改善就是 20%，而且**这是唯一与业务指标挂钩的口径**。

这一条是本次借鉴里最容易被忽略、也最关键的判断：**Tadpole 用 skip connection 的理由，
正是"细尺度结构在全局损失里权重太小"**。

## 4. 可直接借鉴的（按优先级）

| 项 | 我们的落地 | 状态 |
|---|---|---|
| **① 零初始化 skip connection** | A'' 的残差基，k=0 退化为 A' | ✅ **已实现并验证**（全局 −23%，深处 −20%） |
| **② 重建优先于动力学** | 与路线 A 的失败结论一致：动力学目标太难，且我们的场空间格局本就高度持久 | ✅ 已被我们的实测独立印证 |
| **③ LoRA 式低秩适配** | 换城市时只训练低秩残差，不动内核与模板 | ⏳ 待做（需要第二个城市的台账） |
| **④ 在线生成 + 缓冲** | `typhoeus.scenegen` 已是"即时生成"，但目前落盘 260 MB | 🟡 可改为内存 FIFO，省掉 I/O |

## 5. 不能照搬的（三条，都有具体理由）

### 5.1 GPU 伪谱求解器——我们的求解器不是频谱法

Tadpole 的在线生成依赖 **FFT 伪谱 + ETDRK 时间积分**，在 GPU 上是毫秒级。
我们的内核是**图守恒律 + Green-Ampt + Ghil-Sellers**，CPU 单场 **6.3 s**，且拓扑不规则
（27 涝点 + 排水边），**无法用 FFT**。

⇒ 我们做不到 Tadpole 那种"边算边训"。要么写 GPU 版内核（会动复算指纹，代价大），
要么接受"先批量生成再训练"（我们现在的做法）。

### 5.2 202 TB 对 260 MB——量级差 6 个数量级

Tadpole-S 有 8.8M 参数，预训练用等效 202 TB。我们 60 场共 **260 MB**，
模型约 5 万参数。**"基础模型"这个词在这里不成立**——我们做的是**单城市的专用代理**，
不是跨系统基础模型。这一点在对外表述上必须守住。

### 5.3 零样本跨 PDE 系统——我们的异质性是"城市"，不是"物理"

Tadpole 的迁移是跨方程（KS / Burgers / MHD / 湍流）。我们只有一个物理
（图守恒律），异质性来自**城市地形与管网**。所以"零样本迁移"对我们是
**换城市**，而换城市恰恰需要新的台账与 DEM——不是换个权重就能解决的。

### 5.4 三维空间 vs 我们的二维+时间

Tadpole 处理 `[B,C,X,Y,Z]` 三维空间。我们是 `(T, Y, X)`：时间轴是**因果**的，
不能像空间轴那样随机裁剪跨越——沿时间裁会切断因果链。因此 crop 只能做空间向。

## 6. 结论与建议

1. **值得借鉴，而且已经借到实处**：零初始化 skip connection 让 A'' 几乎追平 oracle
   （全局 0.0096 / 深处 0.0201，对应 97.9% / 99.5%）。
2. **本文最重要的方法论提醒**：**损失口径决定你看得见什么**。
   全局 NMSE 会掩盖我们要修的细尺度错误；必须用"深处 1% 格点"或台账点位口径复核。
3. **不建议追 foundation model 的叙事**：数据量、求解器形态、异质性来源都不同。
   我们的正确定位是**单城市情景代理**，可迁移性靠 LoRA 式的低秩适配，不靠零样本。
4. **A'' 仍不修复点位水深**：残差基是从内核自身残差学的，**学不到内核没有的物理**
   （管网顶托）。深处格点误差 0.0201 是"内核能给出的最好"，不是"真实的涝点深度"。
