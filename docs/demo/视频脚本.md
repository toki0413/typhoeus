## 录制清单

1. `python -m typhoeus.cli run`（先跑一次预热缓存）
2. `start_web.ps1` 打开值班台，录三个数字与五个问题按钮
3. 录一次域外坐标的拒答（例如 121.15, 30.03）
4. 录一次 `--sinks` 全链，展示命中率 64.7%

## 三条纪律

- 画面里的数字必须与 `out/` 产物一致，录前重跑一次
- 拒答镜头不要剪掉：它是产品的一部分
- 结论页停 3 秒再结束
