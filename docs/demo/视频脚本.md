## 旁白配音

若改为真人配音，按上表逐句念即可，语速约 4.5 字/秒，总长控制在 1:50 以内。字幕已经烧在画面里。

## 录制方法（可复现）

```bash
# 1) 起值班台
python -m typhoeus.webapp --port 8830
# 2) 起无头 Edge（CDP 端口 9333）
msedge --headless=new --remote-debugging-port=9333 --window-size=1920,1080 about:blank
# 3) 录制脚本：真实点击/输入/导航 + 定频截帧
node .scratch/capture_tour.cjs
# 4) 合成：分段编码后拼接，字幕逐帧烧入
python .scratch/build_tour_v2.py
```

画面没有加速、没有剪接；只有片头卡、两张结果卡、片尾卡是静态图。
