# ADR-0001：typhoeus 的第一目标函数是"个人能力跳板"，不是现金流

日期：2026-10-16
状态：已采纳

## 背景

本项目原为"城市内涝情景推演与验收工具"。2026-10-16 一轮独立评估与实测把它的核心主张判死：

- 绝对水深由反算常数决定（`config.py:56-58`：定标依据是"让 334 mm 雨量出 0.94 m 水深"），
  参数族内峰值水深跨 0.205–1.367 m（4.6 倍）。
- 涝点水深命中率 0%、MAE 0.359 m；12/17 个实测涝点模型内几乎没有积水。
- 换降雨驱动（ERA5 / ERA5×2 / 参数化，面雨量 259/518/202 mm）覆盖率恒 29.4% → 数据侧无解。
- ±100 m 坐标扰动的覆盖率带为 11.8%–35.3%，中位 23.5% → 坐标修正也救不动，47% 目标撤销。
- `01_preset_plan.json` 的 p95 实为 `clip(1.15)^1.4` 常数乘子，不是分位数估计。

随后提出的五个变现形态（继续做模型、模型验收工作台、数据集诚信评级、MRM 基础设施、
应急作业单签发引擎、做空式第三方验证所）被依次否决，原话为"很无聊"、"完全不硅谷"、
"我就明显不买单"、"这些都很蠢"。

## 决策

**本项目的成功判据改为：它能否提升负责人本人的市场价值与可选性。**
收入、融资、客户数均降为次要或不承担判据作用。

## 由此得出的一条筛选规则（写下来，防止再走回头路）

没有人会为"证明自己的交付物不合格"付钱；只有"证明别人的不合格"才有人付钱。
因此凡以"自我审计/可追责工件"为核心的商业形态，默认不成立——
它们可以服务"能力跳板"这个目标，但不能被当作生意来 pitch。

## 影响

- 后续所有方案讨论的评价维度换成：能否产出**他人无法轻易伪造的能力证据**
  （可复算记录、公开判词、跨领域可迁移的方法），而非"有没有买方"。
- 水动力内核不再是必须救活的资产；它的作用是"亲手把自己的主张打到死"的那段可验证经历。
- 保留资产：三态判定框架、来源分级、双口径强制并报、误差带、复算指纹、
  事件不相交 CV、结构探针先行的流程。
