## 1. 产品定位

**一句话**：城市内涝情景推演与工程决策支持系统。

**产品类别**：规划决策类计算工具（不是监测预警平台，不是预报系统）。

**价值主张**：把一次台风过程换算成三类可执行决策——
**投哪里**（布点与改造优先级）、**投多少**（投入区间与损失下降）、**先修谁**（恢复次序）。

| 维度 | 内容 |
|---|---|
| 客户 | 市政规划设计院、区水务局、防汛指挥部、韧性城市咨询机构 |
| 使用时机 | 汛前预置、汛中响应分档、灾后复盘、工程立项与方案比选 |
| 交付形态 | 三件岗位可用件（值守布点表 / 影响评估单 / 方案比选件）+ 机器可读底座 |
| 技术特征 | 确定性物理内核 + 多情景集合 + 三态门槛体检 + 双指纹复算 |
| 部署方式 | 纯 CPU 单机；单次全链约 27 s；零 API key、零外部服务依赖 |

## 3. 场景库（标准场景 + 使用方式）

### 场景 S1 · 汛前预置（谁在何时用）
- **用户**：区水务局防汛值班室 · 汛前 1–2 周
- **输入**：目标片区、历史情景档（p50–p95）
- **输出**：p1 值守与布点表——值守等级、巡查频次、人员装备配置、优先点位清单
- **现状可交付**：✅ 已实现（`out/p1_汛期值守与布点表.html`）
- **成功判据**：值班室照表可直接排班，不需再读其他文档

### 场景 S2 · 汛中响应分档
- **用户**：防汛指挥部 · 台风影响期
- **输入**：实时雨情（对接气象/雷达接口后自动匹配情景档）
- **输出**：当前应启动的响应等级与动作
- **现状可交付**：⚠️ 情景档与动作表已就绪；**实时雨情入口未接**（见 §7）
- **成功判据**：雨情进入某档后 5 分钟内给出对应动作

### 场景 S3 · 灾后复盘
- **用户**：区水务局 / 街道 · 事件结束后 7 日内
- **输入**：事件场次
- **输出**：影响评估单（损失总量与四项构成）+ 逐点对账记录
- **现状可交付**：✅ 已实现（`out/p2_片区影响评估单.html`）
- **成功判据**：复盘材料中的损失数字可直接引用且可溯源到指纹

### 场景 S4 · 工程立项与方案比选（核心商业场景）
- **用户**：市政规划设计院 · 项目前期
- **输入**：候选方案（布点 / 改造 / 泵站）
- **输出**：方案比选件——投入区间、对应损失下降、每降 1% 损失所需投入、推荐次序
- **现状可交付**：✅ 已实现（`out/p3_方案比选与投入建议.html`）
- **成功判据**：比选结论可作为立项材料的量化附件

### 场景 S5 · 韧性规划长期评估
- **用户**：规划院 · 年度
- **输入**：多年份情景（16 场已标定事件，跨 36 年）
- **输出**：强度—损失关系与情景放大倍数
- **现状可交付**：✅ 关系已标定（Q ∝ 雨量^2.109，R² 0.883，n=14）
- **成功判据**：可回答"雨情加严一档，损失放大几倍"

### 场景 S6 · 遥感淹没范围验证（技术增强项）
- **用户**：技术审查方 · 模型验收
- **输出**：SAR 水面范围与模型淹没范围的重合率（面积型验证，不依赖点位精度）
- **现状可交付**：⚠️ 模型已训成未接入；影像未下载
- **成功判据**：面积型 IoU ≥ 0.5 且优于阈值基线

## 8. 已知偏差声明（随产品交付，一次说清）

1. 点坐标精度为**地名定位近似（±100 m）**；台账 28 条全部如此。
2. **降雨驱动已完成独立交叉验证**：三个相互独立的来源在计算域上一致——
   ERA5 批量 202.5 mm · **CHIRPS-2.0 卫星—站点融合 234.3 mm** · ERA5 单链 259.1 mm
   （域内单站通报 283 mm，同量级）。官方全市口径 375 mm 的差异**来自区域口径**
   （全市含北部暴雨中心余姚 475 mm，非本计算域），**不是模型误差**。
   完整对照见 p2《多源面雨量交叉验证》一节。
3. 单点水深**不作主张**：域内 17 点命中 0%、MAE 0.359 m、12 点模型静默。
4. 模型**不含潮位项**；2021 烟花实测增水（镇海 1.43 / 三江口 1.61 / 北渡 3.0 m）仅作并列读数。
5. **重现期不外推**：经验频率只报样本内实测值（覆盖上限约 36 年一遇）。
6. **工程收益侧未标定**：改造前后积水观测缺失；投入—收益为量级估算。
7. 未纳入：管网顶托高程与过流能力、逐路段通行实测、设施与管网台账。
8. CHIRPS 为 0.05° 粗格网日值，本计算域仅 20 个格点；它用于**量级交叉验证**，
   不替代逐时序列。

| 覆盖 **3,031 县 / 68,623 普查区**，用**多层回归**（county 随机效应 + state 固定效应）处理跨尺度嵌套 | **方法学模板**：本产品"片区级 vs 单点级"两档主张正是跨尺度效应问题；该文给出正规解法（多层模型），本产品当前只用分层统计，列为可升级项 |
| **靠近主要道路会放大风险** | **直接支撑 p1 优先点位筛选口径**（下穿立交/桥洞 + 实测 ≥0.45 m），与"交通走廊邻近性放大复合风险"一致 |
| **密集开发本身不必然提高灾害风险**；开放空间管理部分有效 | 可用于回答"是不是楼太密"这类追问：**密度不是主因，位置与形态才是** |
| 风险在城市中心附近高密度人口区**显著加剧** | 支持本产品把"低洼小区"与"下穿立交"分列不同敏感系数（0.75 / 1.00） |
| 城市形态效应存在**显著空间差异**，需因地制宜 | 支持本产品拒绝全域统一系数，改按结构类型分组（p4 已按此诊断） |

**该文未覆盖而本产品覆盖的**：它是**长期空间格局**统计（多年平均）；本产品是**单场事件的时序推演**，可给出事件内时间序列（p7 逐时雨情与越阈时刻）。两者互补，材料中可并列为"长期格局 + 事件推演"的证据组合。

## 10. 术语与口径

| 术语 | 定义 |
|---|---|
| 情景（p50/p80/p90/p95） | 72 h 面雨量的分位档，200 成员集合、51 分位保序订正 |

| 复算指纹 | `config_hash` + `source_hash`；同指纹下逐位复现 |
