# 世界模型：我们试过、失败了、以及它到底能解决什么

时间 2026-10-18。回应「世界模型呢」。
**结论：已经试过（p12），路线上限已测出，且严格说不构成世界模型。
现在不该再投入——因为我们的瓶颈不是速度，是准度。**

---

## 一、我们有什么：`p12_JEPA代理验收`

`typhoeus/jepa.py`（549 行）实现的是一个 **JEPA 式潜空间动力学代理**：

```
E : 水深帧 → z (32)                     编码器
P : (z_t, 雨帧摘要) → ẑ_{t+1}           潜空间预测器（损失算在 z 上）
D : z → 水深帧                          解码器（仅评估用）
训练目标：L_latent + VICReg 防塌缩 + λ·L_recon
```

训练：**48 情景 / 留出 12 / 73 帧 / 36×68 / 潜维 32 / 3 epochs**

### 三条路线的实测结果

| 路线 | 做法 | 结果 |
|---|---|---|
| **A** | 整场逐帧潜空间滚动预测 | **FAIL**——打不过「持续峰值帧」基线 |
| **A′** | 只预测幅度时间线 `a(t)`，空间用内核峰值帧作固定模板 | **PASS**：NMSE **0.0125** vs 持续性 **0.1129**；达 oracle 上界 **96.6%** |
| **A″** | A′ + 8 维残差 SVD 基（借鉴 Tadpole-DFT 的零初始化缩放） | NMSE **0.0096** vs oracle **0.0094**（差 2%） |

**A 的失败方式是关键信息，不是挫折**：

> 整场潜空间动力学**打不过"记住最湿那一帧"**——说明这个系统的
> **空间格局高度持久**，动力学**近乎时空可分**。
> 所以可学的只有**幅度时间线**，空间模板不是可学项。

这也反过来解释了为什么 `p43/p44` 的"集中度"轴有独立效应（×1.64）：
**结构在模板层面重要，在演化层面几乎不变。**

## 二、但按定义，它**不是**世界模型

LeCun 式世界模型的四要素：

| 要素 | 我们有吗 |
|---|---|
| 编码器 → 潜状态 | ✅ |
| 潜空间动力学（损失在 z 上） | ✅ |
| **动作 / 参数条件**：`P(z, a) → z′` | ❌ **没有** |
| **规划回路**：在潜空间里试探再解码 | ❌ **没有** |

我们的预测器是 `P(z_t, 雨帧摘要)`——**只吃雨，不吃干预**。
所以它能「快进」，但**不能在潜空间里试「如果把顶托抬到 0.5 m 会怎样」**。

> **它是前向加速器，不是世界模型。** 这个区别在对外表述里必须守住。

---

## 三、世界模型真正能解决的是什么

不是"预测未来"——我们的内核已经在做这件事。
**是「不用每试一个干预就跑一遍求解器」。**

而我们的产品核心动作**恰好就是干预**（四轴）：

| 产物 | 内核求解次数（实测记录条目） |
|---|---|
| `p51` 参数集合 | **25** |
| `p43` 集中度×总量矩阵 | **20** |
| `p36` 排水三通道 | 7 |
| `p37` 土层厚度 | 6 |
| `p44` / `p41` | 未逐项统计 |

已知四组已 **58 次**；全仓合计量级在 **60–80 次**，单次约 8–10 s → **约 10 分钟**。

**一个动作条件化的世界模型能把 10 分钟压到毫秒。**

---

## 四、那为什么现在不该做

**因为 10 分钟不是瓶颈。**

| 我们的真实瓶颈 | 数值 |
|---|---|
| 内核 vs SAR 面积一致性 | **IoU 0.0847**（模型水面是 SAR 的 8.1 倍） |
| 点位水深命中率 | **0.0%**（MAE 0.36 m） |
| 参数集合下红格面积中位数 | **0** |
| 损失量 Q 的外部参照物 | **没有** |

> **给一个不准的模型加速，结果是"更快地给出错的答案"。**
> 世界模型优化的是吞吐，我们缺的是有效性。

这与本会话早前"RSI"那次的结论同源：**先把能检测自己错在哪做好，再谈加速。**

## 五、如果将来要做，正确形态与现成验收

### 5.1 最小改动：给预测器加参数条件

```
现在：P(z_t, r_t)        → ẑ_{t+1}
改成：P(z_t, r_t, θ)     → ẑ_{t+1}      θ = 参数向量（顶托/过流系数/土层/不透水率）
```

θ 拼进输入即可，架构不变。这样才第一次具备「潜空间干预」的能力。

### 5.2 我们已经有别人没有的东西：现成的验收数据

**四轴结果就是标准答案**：

| 验收项 | 已有真值 |
|---|---|
| 代理能否复现 `do(顶托)` 的 ×2.81 | `p41` / `p44` |
| 代理能否复现集中度 ×1.64 | `p43` / `p44` |
| 代理能否复现土层 −4.7% | `p37` |
| 代理能否复现排水三通道排序 | `p36` |

**判据应当是"复现干预效应的符号与量级"，而不是 NMSE。**
因为世界模型的用途是干预排序，不是场量逼近。

### 5.3 验收口径建议

| 判据 | 阈值 |
|---|---|
| 四轴杠杆倍数的相对误差 | ≤ 15% |
| 四轴排序不变 | 必须满足 |
| 单次干预推理 | < 0.05 s |
| 分布外（未见参数组合）退化 | 须报，不得隐藏 |

## 六、顺手修的一处事实错误

`docs/product-definition.md` 原写：

> | JEPA / 世界模型路线 | **无先例、无实现**（属方案文档） |

**这是错的**——`p12` 已实现且已判 PASS/FAIL。已改为如实表述：
已实现、路线 A 判 FAIL、A′ 达 oracle 上界 96.6%、A″ 差 2%，
并注明「该代理无动作条件，严格说不是世界模型」。

**这类"把已做过的事写成未做"的错误，比夸大更危险**：
它会让评审以为我们没试过，也会让我们重复投入。

## 八、边界

1. p12 的训练数据**来自内核自身，不是观测**——它学的是内核的近似，不是真实世界。
2. p12 的留出**按情景切分，未做跨事件泛化**。
3. p12 的分辨率降到 36×68（水深取最大池化以保极值），分辨率损失未计价。
4. 「60–80 次内核求解」是**按记录条目估算**，`p44`/`p41` 未逐项统计，故为量级而非精确值。
5. LeCun 式世界模型的要素划分有多种版本；本文按「编码器 + 潜动力学 + 动作条件 + 规划」四项判据，属常见但非唯一口径。
6. 本文不主张世界模型路线应当放弃，只主张**在当前瓶颈下不该优先投入**。
