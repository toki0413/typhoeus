这个 FAIL 说明了什么：模型淹没面积占比 0.189831， SAR 观测 0.023511——模型把水面铺得宽约 8 倍； 但召回率 0.7082 说明它覆盖了大部分真实水面（是超集）。 这与点位诊断（0% 命中、17/17 偏浅）是同一物理事实的两面： 模型的水是摊薄的，不是集中的——缺管网顶托导致水没有在立交处积聚。
SAR 水面含常年河网与湿润地表，不等于新增淹没； 严格做法需旱季基线影像做差，本轮未取。模型阈值 0.05 m 沿用「模型静默」判据。
为什么必须写这一条：本件第二节的留出集指标来自全球事件域 （Ghana / Nigeria / Pakistan / Paraguay / Somalia / Spain / Sri-Lanka / USA / Bolivia / India / Mekong）， 不含宁波。第四节是宁波本地的面积型对照，结论是判据 FAIL—— 把全球指标说成"宁波已验证"就是超范围主张，而把宁波的 FAIL 藏起来就是另一种失真。

五、方法说明

模型U-Net（tools/sar_train.build_model），单通道 VV 裁剪训练，sigmoid 阈值 0.5 出水体二值图
基线Otsu 阈值法（同一批瓦片、同一映射）
数据Sen1Floods11（真实 SAR 影像 + 人工标注），事件级切分
复算权重 SHA256 前 16 位随件给出；判分脚本 tools/sar_train.py
数据来源：留出集指标 cloud_artifacts/*/metrics.json 与 baseline.json；权重 cloud_artifacts/*/unet_ep*.pt； 本地推理数据 .scratch/sar/_selftest_data（合成件）。
复算：本件由 typhoeus.sar_verify 生成；本机推理部分可在 python -m typhoeus.sar_verify 下重复执行。
