# 03 · 检索与证据链

> 检索不是“找几篇支持我的”，而是同时找支持、反例和前沿，再把它们放进同一张台账。

## 1. 检索源选择

| 领域 | 主源 | 补充 | 说明 |
|---|---|---|---|
| 医学/生命 | PubMed | ClinicalTrials、Cochrane、bioRxiv | 注意预印本与同行评审差异 |
| 物理/数学/计算 | arXiv | Crossref、Semantic Scholar、DBLP | 版本差异要核对 |
| 化学/材料 | Web of Science、Scopus | Crossref、arXiv | 注意补充材料 |
| 工程 | IEEE Xplore、Scopus | arXiv、行业标准 | 区分会议与期刊 |
| 经济/金融 | EconLit、SSRN、NBER | Crossref、RePEc | 工作论文需标注 |
| 社会科学 | Scopus、Web of Science | SSRN、领域数据库 | 注意地区与语言偏倚 |
| 人文 | JSTOR、Project MUSE | 图书馆目录、档案库 | 一手材料优先 |
| 跨学科/快速摸底 | Semantic Scholar、Google Scholar | OpenAlex、WebSearch | 仅作线索，回源核验 |

原则：**先用领域主源，再用通用搜索补漏**；通用搜索的结果必须回到原始来源核验。

## 2. 查询构造

### 概念块法

把研究问题拆成 2–4 个概念块，每块列同义词、缩写、上下位词：

```text
(概念 A OR A 的同义词)
AND (概念 B OR B 的同义词)
AND (概念 C OR C 的同义词)
```

### 结构化框架

| 框架 | 适用 | 组成 |
|---|---|---|
| PICO | 医学/干预 | 人群、干预、对照、结局 |
| SPIDER | 质性/混合 | 样本、现象、设计、评估、研究类型 |
| PICOC | 政策/工程 | 人群、干预、对照、结局、情境 |
| 概念块 | 通用 | 2–4 个核心概念 + 同义词 |

### 引文追踪

1. 找 1–2 篇锚点文献（最直接、最权威）。
2. 向前追：它的参考文献里有哪些关键证据。
3. 向后追：谁引用了它，是否出现反例或更新。
4. 横向追：同作者/同团队是否有相反结果。

## 3. 三搜策略

| 层次 | 目的 | 查询写法 | 产出 |
|---|---|---|---|
| 锚点 | 找最直接的支持 | 核心发现 + 机制/理论 | 2–5 篇核心文献 |
| 反例 | 找矛盾与边界 | 同一关系 + null / negative / contrary / fail | 至少 1 篇反例或说明未找到 |
| 前沿 | 找未解问题 | 近 3–5 年 review / perspective / preprint | 1–3 个开放问题 |

**反例搜索是硬要求**：找不到反例，也要写明检索词与范围。

## 4. 核验

对每条准备引用的文献，核验：

1. **存在性**：DOI / PMID / arXiv ID 可解析。
2. **匹配性**：标题、作者、年份、期刊一致。
3. **内容性**：你引用的那句话，确实能在摘要或正文中找到。
4. **状态**：是否撤稿、更正、预印本、掠夺性期刊。
5. **强度**：研究设计能否支撑你用它支撑的主张。

无法核验的引用，一律删除或标注“未核验”。

## 5. 证据记录表

```markdown
| # | 主张 | 文献（Author, Year, ID） | 该文献的具体发现 | 支持/反驳 | 强度 |
|---|---|---|---|---|---|
| 1 |      |                          |                  |            | A/B/C/D |
```

要求：

- “具体发现”写一句话，不用“支持了我们的观点”这种空话。
- 同一主张至少一条支持 + 一条可能的反证（或写明未找到）。
- 预印本、会议论文、工作论文单独标注。

## 6. 检索失败时

按顺序处理：

1. 换同义词、缩写、上下位词。
2. 换语言（中英文）、换数据库。
3. 放宽时间范围，找奠基性文献。
4. 用引文追踪替代关键词。
5. 仍无结果：写“在【数据库/关键词/时间范围】内未检索到”，不要写“没有研究”。

## 7. 引用格式

- 正文：`(Author, Year)` 或编号，按目标期刊要求。
- 文末：APA 7th，包含作者、年份、标题、期刊/出版社、DOI/URL。
- 预印本：标注 `[Preprint]` 与服务器。
- 同一文献多个版本：引用最终发表版，并注明预印本关系。
