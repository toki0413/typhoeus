# 05 · 缺口分析与质量门

> 缺口分析的目的不是列一堆“未来工作”，而是回答：哪一步断了，补什么能接上，补不上时结论要降到哪。

## 1. 缺口分类

| 类型 | 问题 | 典型信号 |
|---|---|---|
| 设计 | 因果识别不成立 | 无对照、无随机化、无识别策略 |
| 测量 | 指标不测量目标构念 | 只有代理指标、信度/效度缺失 |
| 样本 | 样本不足或偏 | n 小、选择偏差、单一人群 |
| 分析 | 方法不匹配数据结构 | 伪重复、多重比较、模型假设未检验 |
| 复现 | 结果不可重复 | 无代码/数据、无独立重复 |
| 外推 | 超出研究情境 | 实验室到现场、单一地区到全国 |
| 伦理 | 合规与隐私 | 知情同意、脱敏、dual-use |
| 文献 | 证据链不完整 | 缺关键对照文献、反例未处理 |

## 2. Track A：可执行的补全方案

按范式给动作，不写“建议进一步研究”这种空话。

| 范式 | 补全动作 | 判定标准 |
|---|---|---|
| 受控实验 | 加对照/剂量梯度/盲法/独立重复 | 预注册的主要结局出现可重复效应 |
| 观察研究 | 加混杂控制、负对照、工具变量/断点/DID | 识别假设可检验，稳健性通过 |
| 计算/仿真 | 加独立基准、消融、敏感性分析、外部验证 | 在未见数据上不劣于基线 |
| 工程测试 | 加压力/故障注入/长期运行 | 预定义指标在置信区间内达标 |
| 质性 | 加受访者类型、反例分析、成员校验、编码审计 | 主题在新增材料中仍成立 |
| 混合方法 | 让量化与质性回答同一问题 | 两套证据收敛或能解释分歧 |
| 理论 | 明确假设、给出可检验推论 | 推论能被经验数据证伪 |
| 政策评估 | 加平行趋势、安慰剂检验、外溢检查 | 识别策略通过稳健性检验 |

每条方案写清：**动作、样本/材料、对照或比较、判定指标、失败后的解释**。

## 3. Track B：文献逻辑补全

无法补数据时：

1. 找 2–3 条独立证据线（不同团队、不同方法、不同情境）。
2. 写清它们与本研究的连接点与差异。
3. 给出一个能整合它们的机制/理论解释。
4. 明确哪些环节仍是推断，并给出可证伪的预测。
5. 不得把“多条间接证据”写成“已证明”。

## 4. 对抗性自检 12 问

1. 我是否默认了某个学科或范式？
2. 图上直接可见的事实有哪些？我是否把推断写成了事实？
3. 每条主张的直接证据是什么？强度几级？
4. 我是否只找了支持文献，没找反例？
5. 有没有把相关写成因果、把仿真写成实测？
6. 效应量、样本量、不确定性写了吗？
7. 统计显著是否被当成实际重要？
8. 多重比较、伪重复、选择偏差检查了吗？
9. 结论是否超出了样本、情境、尺度？
10. 引用是否可核验？有没有撤稿/预印本未标注？
11. 最可能被审稿人攻击的三处是什么？
12. 如果主结论是错的，最可能的原因是什么？

## 5. 阻断式质量门

以下任一项不通过，不得交付：

- [ ] 学科/范式已判定，或假设已显式写出。
- [ ] 每条 Result 主张都有直接证据与强度标注。
- [ ] 至少处理了一个替代解释或反例。
- [ ] 效应量与不确定性已报告（定性研究写可信度/一致性）。
- [ ] 结论措辞与证据强度匹配。
- [ ] 所有引用可核验，格式统一。
- [ ] 已写边界声明。

## 6. 边界声明模板

```text
边界声明
- 材料：本文解读基于【图/数据/文本】，未包含【缺失材料】。
- 假设：按【领域/范式】解读，关键假设为【假设】。
- 证据：主结论为【A/B/C/D】级；其中【某条】仍属推断。
- 外推：结论适用于【范围】，不适用于【范围】。
- 未决：需要【补全动作】才能判断【问题】。
```
