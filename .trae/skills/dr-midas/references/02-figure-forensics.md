# 02 · 图表取证

> 目标：把“图上看到的”与“你解释出来的”彻底分开，再判断解释能走多远。

## 1. 通用解剖清单（12 项）

逐项回答，缺项就写“未标注”：

1. **图类型**：柱、折线、散点、箱线、热图、火山、生存、森林、地图、网络、影像、示意图、编码图。
2. **X/Y 轴**：变量名、单位、线性/对数、范围是否从零开始。
3. **图例**：颜色/形状/线型分别代表什么，是否与正文一致。
4. **样本量 n**：每个组的 n、重复层级（技术重复还是生物学/独立重复）。
5. **中心与离散**：均值/中位数、SD/SEM/CI、误差线含义。
6. **显著性**：检验方法、阈值、多重比较校正、是否只标星号。
7. **效应量**：差异有多大，是否报告区间。
8. **缺失与异常**：缺失点、离群点、被剔除的数据。
9. **变换与平滑**：标准化、log、归一化、滑动平均、插值。
10. **比较基线**：对照是什么，是否可比。
11. **视觉编码**：面积/长度/角度是否与数值成比例。
12. **可复现信息**：是否给出数据、代码、统计脚本。

## 2. 常见图型的读法

| 图型 | 先读什么 | 常见陷阱 |
|---|---|---|
| 柱状/条形 | 误差线、n、是否从零 | 截断轴放大差异；3D 透视 |
| 折线 | 时间尺度、采样密度、平滑 | 平滑掩盖拐点；不等间隔当等间隔 |
| 散点 | 关系形状、离群、拟合方式 | 用线性拟合读非线性；忽略聚类 |
| 箱线/小提琴 | 分布形状、偏态、离群 | 只报中位数掩盖双峰 |
| 热图 | 色阶、标准化方向、聚类 | 色阶饱和；行/列标准化改变结论 |
| 火山图 | 效应量 vs 显著性、阈值 | 只读 p，不读 fold change |
| 生存曲线 | 删失、风险表、log-rank | 忽略非比例风险；样本后期过少 |
| 森林图 | 效应量、CI、异质性 | 把汇总效应当个体效应 |
| 地图/空间 | 投影、尺度、图例分级 | 可变面元问题；色阶误导 |
| 网络图 | 节点/边定义、布局算法 | 布局距离被当成相似度 |
| 影像 | 对比度、缩放、代表性 | 只展示“好看”的切片 |
| 示意图 | 哪些是数据、哪些是假设 | 把假想机制当已证事实 |
| 质性编码图 | 编码定义、引文、一致性 | 主题数量当普遍性 |

## 3. 视觉陷阱清单

- **截断轴**：Y 轴不从零开始，差异被放大。
- **双轴**：两条轴任意缩放，制造“同步”错觉。
- **面积/体积错觉**：半径或 3D 尺寸按数值线性放大，面积呈平方放大。
- **色阶操纵**：彩虹色阶、分段阈值、饱和截断。
- **选择性范围**：只展示有利区间，隐藏平台或反转。
- **过度平滑**：滑动平均抹掉真实波动与拐点。
- **伪重复**：技术重复当独立样本，虚增 n。
- **基线不等**：组间起点不同，却比较终点。
- **幸存者偏差**：只展示完整样本，缺失样本被静默删除。
- **图表与正文不一致**：n、误差线、显著性标记对不上。

## 4. 统计误读清单

| 误读 | 表现 | 纠正 |
|---|---|---|
| p 值当效应大小 | “显著”即“重要” | 报效应量与置信区间 |
| 多重比较未校正 | 大量指标里挑显著的 | 校正或预注册 |
| 功效不足 | 小样本下“无显著差异”当“无差异” | 报功效或等价性检验 |
| 回归到均值 | 极端组第二次变正常 | 设对照或重复测量 |
| 辛普森悖论 | 分组与总体方向相反 | 检查分层结构 |
| 选择偏差 | 样本非随机且与结局相关 | 说明纳入/排除 |
| 测量误差 | 用噪声大的指标下强结论 | 报信度/效度 |
| 模型过拟合 | 训练集好、外部差 | 外部验证与基线对比 |

## 5. 多图论证链

多图不是图集，是一条论证链。逐图回答：

1. 这张图在整条链里承担哪一步（现象、机制、边界、应用）？
2. 去掉它，主结论还成立吗？
3. 它和上一张图是“递进”“并列”还是“互证”？
4. 有没有两张图其实在说同一件事（冗余）？
5. 有没有关键一步没有图支撑（断链）？

输出一张表：

| 图 | 角色 | 支撑的主张 | 与前后图关系 | 是否必要 |
|---|---|---|---|---|

## 6. 取证输出模板

```text
【可见事实】
- 图 1：……（轴/单位/n/误差线/显著性）
- 图 2：……

【解释推断】
- 可能支持：……
- 替代解释：……

【图表风险】
- 截断轴 / 伪重复 / 色阶 / 缺失 / 与正文不一致：……

【可支持的最高证据等级】A / B / C / D
```
