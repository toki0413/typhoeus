# 06 · 输出模板

> 模板只规定骨架，不规定套话。每一块都必须填入本材料的具体内容。

## 1. 响应骨架

### 短版（单图，≤ 3 个主张）

```text
【判定】领域 / 材料 / 范式 / 关键假设
【图上事实】3–5 条
【主张与证据】表格式，1–3 行
【Result 重构】标题 + 一段
【图注】一段
【值得注意的边界】2–3 条
```

### 长版（多图或整篇论证）

```text
【判定】
【多图论证链】图 → 角色 → 支撑主张 → 是否必要
【主张-证据台账】
【Result 重构】
【图注】
【Discussion】L1 → L2 → L3（按证据允许的层级）
【Gap Analysis】Track A / Track B
【对抗性自检】最可能被攻击的三处
【边界声明】
【参考文献】APA 7th
```

## 2. Result 重构模板

```text
### （结论型小标题）

在【条件/样本】下，【主要发现】。具体而言，【指标】从【值】变为【值】
（效应量【…】，95% CI【…】，n=【…】）。该差异在【子样本/尺度】上成立，
在【另一条件】上不成立。图【X】给出【图型】层面的对应证据。
```

要求：

- 第一句就是发现，不是背景。
- 数字与图对应。
- 最后一句写边界，不写意义。

## 3. 图注模板

### 定量

```text
图 X｜（结论型短句）
（a）【数据来源、样本量、分组】；（b）【中心与误差线含义】；
（c）【统计方法、显著性阈值、多重比较校正】；（d）【一句结论】。
```

### 质性

```text
图 X｜（主题结构短句）
材料来源【访谈/文本/档案】、数量【n】、编码框架【…】、一致性【…】；
节点为【主题】，连线表示【关系】；引文编号【…】；不宣称总体代表性。
```

### 仿真

```text
图 X｜（模型行为短句）
模型【版本】、参数【…】、网格/步长【…】、基准【…】、消融/敏感性【…】；
结果位于模型假设【…】之内。
```

### 地图

```text
图 X｜（空间格局短句）
数据年份【…】、投影【…】、分辨率【…】、分级方法【…】；
灰色为【缺失/无数据】；空间相关不等于过程机制。
```

## 4. Discussion 模板

```text
### L1 机制/理论
【结果】与【已有机制/理论】一致/冲突。支持点：【文献】；反例：【文献】。
可能的解释：【解释 A】与【解释 B】，判别证据是【…】。

### L2 方法
本研究提示【测量/设计/分析】上的【改进/局限】。代价是【…】。

### L3 应用/转化/政策（仅在证据允许时）
在【条件】下，【对象】可据此【行动】；超出【条件】不适用。

### 可检验假说
若【机制】成立，则应观察到【预测】；否则【替代预测】。
```

## 5. Gap Analysis 模板

```markdown
| 缺口 | 类型 | 现有证据 | Track A 补全动作 | 判定标准 | 若不补，结论降级为 |
|---|---|---|---|---|---|
|      | 设计/测量/样本/分析/复现/外推 |          |                  |          |                    |
```

Track B 写法：

```text
现有 2–3 条间接证据（【文献】）指向【解释】；它们与本研究的连接点是【…】，
差异是【…】。因此该解释仍是推断，可证伪的预测是【…】。
```

## 6. 参考文献（APA 7th）

```text
Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), pages. https://doi.org/xxxx
Author, C. C. (Year). Title of preprint [Preprint]. Server. https://doi.org/xxxx
```

规则：只列正文实际引用过的文献；按作者姓氏字母排序；DOI 能写就写。

## 7. 通用示例（非生物）

**材料**：一张折线图，横轴为运行时间（月），纵轴为系统恢复时间（小时），两条策略曲线，阴影为 95% CI。

**Result 重构**

> **策略 A 在中期负载下恢复更快，但优势随规模消失**
>
> 在 6–18 个月的运行区间内，策略 A 的恢复时间中位数为 3.2 h，策略 B 为 5.1 h
> （差值 −1.9 h，95% CI [−2.6, −1.2]，n=24 次故障事件）。该差异在 24 个月后收窄至
> −0.3 h（CI [−0.9, 0.4]），不再支持“持续优势”的解释。图 2 给出两策略的时程与区间。

**图注**

> 图 2｜策略 A 的恢复优势集中在中期的中等负载区间。（a）24 次故障事件的恢复时间；
> （b）中位数为中心，阴影为 95% CI；（c）按事件聚类计算的 bootstrap 区间；
> （d）24 个月后组间差异不再显著。

**Gap（片段）**

| 缺口 | 类型 | Track A | 判定标准 |
|---|---|---|---|
| 后期样本少 | 样本 | 补 24–36 个月事件，按负载分层 | 每层 ≥ 20 次事件，CI 宽度 < 1 h |
| 未控制负载 | 设计 | 按负载分层或回归调整 | 分层后方向一致 |

**边界声明**

> 结论基于单一系统的 24 次事件，适用于 6–18 个月、中等负载区间；长期与高负载区间不适用。
