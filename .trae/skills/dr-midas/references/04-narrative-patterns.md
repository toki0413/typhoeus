# 04 · 叙事模式与措辞校准

> 好叙事不是把结果说大，而是让读者清楚：你看到了什么、这说明了什么、还不能说明什么。

## 1. Result 小标题模式

| 模式 | 结构 | 通用示例 |
|---|---|---|
| 发现 + 关系 | A 随 B 变化，呈 C 关系 | “处理强度与响应呈饱和关系” |
| 对比 + 条件 | 在 X 条件下，A 高于 B | “高负荷条件下，方案 A 的恢复时间更短” |
| 反直觉 | 与预期相反，A 却…… | “增加采样频率反而降低了估计稳定性” |
| 梯度/剂量 | A 随剂量/强度单调/非单调变化 | “误差随网格加密先降后升” |
| 边界 | 效应只在……范围内成立 | “优势仅在中尺度区间出现” |
| 机制线索 | A 通过 B 关联 C | “差异主要由测量误差而非真实效应解释” |
| 方法贡献 | 新方法在……上优于基线 | “在同等预算下，该策略覆盖更多关键节点” |

要求：标题给结论或关系，不写“图 3 的结果”这种空标题。

## 2. Result 段落四拍

1. **发现**：一句话说清最重要的观察。
2. **证据**：给出统计量/效应量/区间/样本量，指向具体图。
3. **边界**：说明在哪个条件、哪个子样本、哪个尺度上成立。
4. **一句意义**：只写一句，不抢 Discussion 的活。

反模式：先讲机制再讲数据；只报 p 值；把每个点都写成“显著”；用形容词代替数字。

## 3. 图注模板

### 定量图

```text
图 X｜（结论型短句）
（a）数据来源与样本量；（b）中心与误差线含义（mean ± SD / median [IQR] / 95% CI）；
（c）统计或推断方法、显著性阈值与多重比较校正；（d）关键结论一句。
```

### 质性/编码图

```text
图 X｜（主题结构短句）
编码来源（访谈/文本/档案）、受访者/材料数量、编码框架与一致性指标；
引文编号与主题关系；不宣称总体代表性。
```

### 仿真/模型图

```text
图 X｜（模型行为短句）
模型版本、参数设置、网格/步长、基准对比对象、消融或敏感性分析；
说明结果位于模型假设之内。
```

### 地图/空间图

```text
图 X｜（空间格局短句）
数据年份、投影与分辨率、分级方法与色阶、边界与缺失区域；
不把空间相关直接解释为过程。
```

## 4. Discussion 四层楼梯

按顺序上升，每层都有准入条件：

| 层 | 内容 | 准入条件 |
|---|---|---|
| L1 机制/理论 | 结果与既有机制/理论的关系 | 有直接证据或强一致的多条线索 |
| L2 方法 | 对测量、设计、分析的启示 | 能指出具体改进与代价 |
| L3 应用/转化 | 对实践、临床、工程、政策的意义 | 有外部效度证据或明确的条件限定 |
| L4 领域/认知 | 对领域假设、范式、议程的影响 | 有跨研究一致性，且能承受反例 |

规则：**上一层没有站住，不跳层**。只有 C 级证据时，最多写到 L2，并以假说形式表达。

## 5. 措辞校准

| 证据强度 | 推荐动词 | 避免 |
|---|---|---|
| A | shows, demonstrates, establishes | may, might |
| B | indicates, supports, is consistent with | proves |
| C | suggests, points to, is compatible with | demonstrates |
| D | may, raises the possibility, we speculate | shows, proves |

中文对应：

- A：表明、显示、证实（在限定范围内）。
- B：支持、指示、与……一致。
- C：提示、可能、与……相容。
- D：或可、有待检验、我们推测。

## 6. 三种叙事角度

| 角度 | 适合 | 风险 |
|---|---|---|
| 机制/理论 | 有较完整证据链 | 证据不足时容易过度解释 |
| 方法/工具 | 新方法、新数据、新基准 | 只谈性能，不谈适用边界 |
| 应用/转化/政策 | 有外部效度或情境证据 | 把实验室结果直接外推 |
| 反常识 | 结果稳健且反例充分 | 为了新意而夸大差异 |

选择矩阵打分（1–5）：证据支撑、解释力、新意、可辩护性。总分最高者为主轴，但**证据支撑低于 3 分不得作主轴**。

## 7. 反模式

- 形容词堆砌：“显著、显著、非常显著”，没有效应量。
- 机制先行：先讲通路/理论，再补数据。
- 空泛拔高：“具有重要理论和实践意义”，不说对谁、在什么条件下。
- 只引顺耳文献：不处理反例。
- 把“未检索到”写成“首次发现”。
- 把模型输出写成“系统行为”。
- 用“趋势”掩盖样本不足。
