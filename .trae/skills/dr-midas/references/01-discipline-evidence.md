# 01 · 学科判定与证据标准

> 这份文件解决两件事：这份材料属于哪个领域；这个领域的“好证据”长什么样。

## 1. 判定信号

| 信号 | 观察点 | 可能推断 |
|---|---|---|
| 术语与变量名 | 基因/蛋白、应力/应变、收益率、编码类别、档案年代 | 学科与子领域 |
| 图表类型 | 生存曲线、相图、森林图、主题编码图、GIS 图层 | 研究范式 |
| 单位与量纲 | μM、MPa、bp、%、人年、置信区间 | 测量层级与统计传统 |
| 统计/推断方法 | t 检验、混合效应、DID、扎根理论、有限元 | 证据标准 |
| 样本描述 | n、受试者、样本点、访谈人数、模型网格 | 推断边界 |
| 引文风格 | 作者-年份、编号、预印本比例 | 领域惯例 |
| 数据来源 | 实验台、观测站、问卷、档案、仿真 | 证据类型 |

判定不确定时，输出：

> 我按【领域 A】的【范式】读这份材料；若它其实属于【领域 B】，受影响的解读是……

不要把不确定藏起来。

## 2. 九类研究范式

| 范式 | 典型材料 | 核心证据 | 常见威胁 | 不能直接推到 |
|---|---|---|---|---|
| 受控实验 | 处理组/对照组、剂量梯度 | 随机化、对照、重复 | 混杂、伪重复、操作者偏差 | 现场与人群 |
| 观察/队列 | 时间序列、暴露-结局 | 时间顺序、剂量反应、混杂控制 | 选择偏差、混杂、反向因果 | 因果机制 |
| 计算/仿真 | 相图、收敛曲线、消融 | 基准对比、消融、敏感性分析 | 过拟合、基准泄漏、参数选择 | 真实系统 |
| 工程/系统测试 | 性能曲线、故障注入 | 可重复基准、置信区间、压力测试 | 测试集偏差、环境差异 | 长期运行 |
| 质性研究 | 访谈引文、编码树、主题表 | 编码一致性、反例、成员校验 | 样本单一、研究者立场、过度概括 | 总体比例 |
| 混合方法 | 量表 + 访谈 | 量化与质性互证 | 两套证据脱节 | 单方法结论 |
| 理论/形式化 | 定理、证明、模型 | 假设显式、推导可检验 | 假设不现实、边界条件 | 经验事实 |
| 人文/档案 | 文本、手稿、图像 | 来源批判、互证、语境 | 选择性引用、时代错置 | 统计规律 |
| 政策/经济评估 | DID、断点、事件研究 | 识别策略、平行趋势、稳健性 | 处理内生、外溢、预期效应 | 普遍适用 |

## 3. 证据强度（领域相对）

### A 级：可以直接下结论

- 实验：随机化 + 对照 + 独立重复 + 效应量。
- 观察：识别策略清楚、混杂控制充分、结果稳健。
- 计算：与独立基准对比、消融完整、敏感性分析通过。
- 质性：多来源三角互证、反例分析、编码可审计。
- 理论：假设明确、证明完整、边界条件清楚。

### B 级：可以下有限结论

- 设计基本成立，但样本、测量或外部效度有限。
- 结果方向稳定，但效应量区间较宽。
- 只有单一数据源，但有内部一致性检查。

### C 级：只能提示

- 相关性、单例、事后分析、模型推演、未预注册的探索。
- 质性材料只有单一受访者或单一场景。
- 仿真尚未与实测对齐。

### D 级：只能作为假说

- 类比、轶事、专家意见、未经验证的机制猜想。
- 叙事上可以提出，但不得写成“发现”。

## 4. 越界清单（出现即降级）

| 越界 | 典型句式 | 处理 |
|---|---|---|
| 相关当因果 | “X 导致 Y” | 改为“X 与 Y 相关；因果需要……证据” |
| 仿真当实测 | “系统会……” | 改为“模型在……假设下预测……” |
| 单例当普遍 | “研究发现……” | 写明样本与情境，限定外推 |
| 质性当代表性 | “大多数人认为……” | 改为“在本研究的受访者中……” |
| 显著当重要 | “显著，因此有意义” | 补效应量与实际意义 |
| 拟合当外推 | “模型可用于预测” | 写明训练域与外部验证 |
| 预印本当定论 | “已证明” | 标注预印本，改“报告称” |
| 模型系统当目标系统 | “对目标系统有效” | 标注模型与目标系统的差异 |
| 实验室当现场 | “实际效果为……” | 写明实验条件与现场差异 |
